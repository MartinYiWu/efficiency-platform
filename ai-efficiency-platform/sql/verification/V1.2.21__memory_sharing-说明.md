# V1.2.21 显式白名单共享

仅新增本模块scope/member/grant/projection四表。scope是记忆ACL，不是业务project，不授予客户/候选/订单/项目源正文权限。默认`aiep.memory.sharing-enabled=false`，生产不会隐式DDL；不开模型/Embedding/新预算。

发布策略还须有合法原fields/artifacts及`sharing:{enabled:true,fields:["response.language","response.detail_level","response.format"]}`，目标context.sourceTypes显式包含`MEMORY_SHARE_GRANT`及原USER决定。仅operations/customer-service，HR评分不注入。每个共享源必须当前ACTIVE且完整依赖全是本人的USER_PREFERENCE_DECISION；聊天/summary/提议传递源拒绝。共享期限不能超过原值/ACL期限，读取不续期。

scope由owner申请、独立指定approver批准（Identity当前`memory:share:approve`）；ORGANIZATION额外`memory:share:organization`；DEPARTMENT创建、接受、读取都核当前部门。成员仅邀请不即读，本人接受后才有投影，退出只撤自己的投影。每个grant/成员revision与原item版本独立，撤权不改原私有item/version。

撤销先推进目标MEMORY_SHARE_GRANT源三epoch/tombstone和投影REVOKED、发布原outbox；旧packet/历史依赖立即拒绝，dispatcher复用原AiInvokeFacade.cleanupMemoryExecution清原execution全thread，8次/24小时有界CPU补偿。未知cleanup不假完成，保BLOCKED。使用后禁止回滚删除锚。无数据库已执行证据；迁移前需precheck审阅/隔离正逆/verify，未授权不执行共享库。

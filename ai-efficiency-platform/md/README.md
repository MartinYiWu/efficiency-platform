# 项目级设计文档索引

> 状态：有效  
> 适用范围：项目级架构、跨模块边界与技术决策

`md/` 保存会改变或解释工程架构的设计、ADR、跨模块契约说明和实施结果。稳定且已确认的当前架构事实必须同步进入 `docs/`，避免 `md/` 成为第二份长期基线。

## 使用规则

- 项目级设计命名为 `YYYY-MM-DD-主题-详细设计.md`。
- 架构决策命名为 `ADR-<三位序号>-主题.md`。
- 验证或实施结果命名为 `YYYY-MM-DD-主题-验证结果.md`。
- 模块内部的普通实现过程、SQL 脚本和执行清单不进入本目录。
- 被替代内容移入 `md/archive/`，并在索引和文档头部记录替代关系。

当前稳定架构基线见：[Java 端架构与开发约束](../docs/architecture/Java端架构与开发约束.md)。

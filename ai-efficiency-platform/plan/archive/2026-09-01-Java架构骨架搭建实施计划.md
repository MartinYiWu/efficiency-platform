## 目标

建立可编译的 Java 21 / Spring Boot 3.2.5 单体多模块骨架，形成根 Maven Reactor、13 个模块、平台公共能力、AI 调用边界与可执行的 ArchUnit 架构门禁。

## 已完成范围

1. 建立 L0、L1、L2、L3 与 `aiep-boot` 的 Maven 模块依赖矩阵。
2. 建立 `ApiResponse`、`TraceIdHolder`、`TraceIdFilter`、启动类与 `/api/platform/ping` 入口。
3. 建立各模块 API Facade，明确 `AiInvokeFacade`、7 个 Agent 端点常量和任务状态模型。
4. 建立模块依赖、Controller/Repository、API 泄露、Agent 传输隔离与包循环的 ArchUnit 测试。
5. 建立 Dockerfile、基础配置、架构基线和初始工程说明。

## 实际验证

- `mvn clean test`：通过。
- `mvn package -DskipTests`：通过。
- 本次治理调整后再次执行 `mvn -q -pl :aiep-boot -am test`：通过。

## 非范围与后续约束

业务 CRUD、真实数据库结构、Agent HTTP/SSE 实现、流式持久化和任务轮询未在本计划实现。云模型密钥、`filter_scope` 语义、任务恢复、向量补偿与 Java–Agent 签名认证须在进入真实 Agent 实现前独立设计并评审。

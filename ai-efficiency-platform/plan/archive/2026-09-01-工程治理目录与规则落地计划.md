# 工程治理目录与规则落地实施计划

**目标：** 建立 Java 工程统一的协作入口、规则、设计、计划与 SQL 治理目录，使后续开发具备唯一且可追溯的约束来源。

**架构：** 根 `AGENTS.md` 负责执行入口与规则优先级；`rule/` 维护持续有效的强制规则；`md/` 和 `plan/` 分别保存设计决策与实施闭环；`sql/` 集中保存本单体多模块工程的数据库资产。`docs/` 继续承载已确认的稳定架构基线。

**技术栈：** Java 21、Spring Boot 3.2.5、Maven Reactor、MyBatis-Plus、Flyway 迁移约定、ArchUnit。

## 全局约束

- 工程根包固定为 `com.aiep`，唯一启动模块为 `aiep-boot`。
- Maven 模块依赖必须符合既定 L0、L1、L2、L3 分层；禁止反向依赖。
- 项目文档使用中文标题和正文；文件名可使用日期、版本号、中文主题和必要的技术标识。
- SQL 不得包含真实密钥、生产数据或未经授权的破坏性操作；已执行迁移不可修改。
- 未经用户明确授权，不执行数据库写入、部署、外部调用或删除操作。

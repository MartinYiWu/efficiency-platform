# 实施计划索引

> 状态：有效  
> 适用范围：项目级实施计划、执行记录与验证结果

`plan/` 记录如何把已确认设计转化为可验证的工程变更。设计说明“是什么、为什么”，计划说明“改哪些文件、按什么步骤、如何验证和回滚”。

| 目录 | 内容 |
|---|---|
| [active/](active/README.md) | 待执行、执行中或待验收的当前计划 |
| [archive/](archive/README.md) | 已完成、取消或被替代的历史计划 |

每个计划必须包含背景、目标、范围、非范围、文件清单、执行步骤、验证、回滚、验收和风险。当前计划清单见 `active/README.md`。

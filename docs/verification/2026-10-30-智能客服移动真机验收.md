## 环境准备

1. 记录手机型号、系统版本、浏览器及版本、输入法及版本、屏幕方向、显示缩放、测试人和时间。Android Chrome 与 iOS Safari 应各保留独立结果；只有一种设备时另一种标记未验证。
2. 由现场操作者确认测试手机可以访问本地开发服务。已有环境前端为主机 `127.0.0.1:5173`、Java 为 `127.0.0.1:8080`，手机自己的 `127.0.0.1` 不指向开发主机。不得把主机回环 URL 直接当作手机可访问地址。
3. 若现场已安装 ADB、Android 已开启 USB 调试且授权本机，可先运行 `adb devices -l`，确认目标序列号状态为 `device`，再由现场操作者设置 `adb -s <序列号> reverse tcp:5173 tcp:5173`。测试结束使用同一序列号 `reverse --remove tcp:5173` 撤销。不得未确认便改监听、开公网或安装驱动。iOS 或无 USB 转发环境由现场提供已批准的内网访问方式。
4. 确认前端对 API 使用现有代理、Java/Agent 健康；使用已批准的开发验收会话和问题，不填写真实个人信息。记录会话 ID、Run ID、前端/后端版本及索引/模型版本，便于区分真实 API 和 fixture。

## 实体手机逐项操作

| 项目 | 操作 | 通过条件 |
| --- | --- | --- |
| 软键盘与多行输入 | 竖屏进入智能客服，点击输入框，使用中文输入法联想输入七行文字；收起再打开键盘 | 光标和输入内容可见，发送/停止按钮可触达；输入区不被键盘遮挡，无整页水平溢出 |
| 中文组合输入 | 联想词尚未确认时按输入法确认键，再正常发送一次 | 不因组合输入误发送；正常发送只创建一次用户消息/Run |
| 长会话滚动 | 打开已有长会话，滚到历史中段，开合键盘，在底部接收长回答 | 消息区独立滚动；输入区仍可触达；不意外跳回或遮住最后消息；可回到底部 |
| 屏幕与视口变化 | 键盘展开时旋转横屏，再回竖屏；收起键盘、切换浏览器地址栏展开状态 | 布局恢复、输入文字保留，无按钮挤出屏幕或无法滚动区域 |
| 抽屉与焦点 | 打开会话导航，选择其他会话，关闭抽屉并回到输入框 | 抽屉/遮罩关闭正确，选中会话一致，焦点与键盘可恢复 |
| 流式与取消 | 发送批准的问题，观察阶段进展、首正文、完成；另一次点击停止 | 阶段提示与正文分开；停止不产生伪成功；按钮恢复可用，无重复提交 |
| 引用与反馈 | 展开真实回答引用，检查来源并对批准的开发验收消息提交反馈 | 引用可读且归属正确；反馈状态明确，标记为开发验收，保留 message/Run 归属 |
| 切后台与恢复 | 流式期间锁屏或切后台后返回；另在弱网/短暂断网下恢复 | 无不可操作遮罩；断线/恢复状态明确，不显示伪完成，不重复创建消息 |
| 可触达性 | 使用系统放大字体，检查引用、反馈、输入和导航控件 | 文字和按钮可读可触达，核心操作不依赖悬停 |

发现问题时先记录精确复现步骤、截图/录屏和 Run；修复前补可观察行为的回归测试。本清单本身不表示这些步骤已经执行。

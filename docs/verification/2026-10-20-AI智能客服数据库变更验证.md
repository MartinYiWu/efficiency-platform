## 5. 执行异常与修复

第一次 Java DDL 在 `pf_file_object` 创建前失败，错误为 MySQL 唯一索引超过 3072 字节。根因是 `utf8mb4` 下 `storage_provider + object_key(1024)` 最大索引宽度为 4224 字节。由于对象 Key 由服务端生成，将 `object_key` 收敛为 512 字符后最大索引宽度为 2176 字节。失败后核对目标表数量为 0。

第二次 Java DDL 在 `ai_prompt_variable` 前失败，错误为 `sensitive` 命中 MySQL 保留关键字。执行精确回滚后核对 29 张目标表数量为 0，再将该列名使用反引号转义。未改变业务字段名称。

第三次执行完成。MySQL 输出了 `TINYINT(1)` 显示宽度弃用提示；该提示来自当前 MySQL 兼容语法，不影响列类型、约束或本次验证结论，后续迁移不修改已执行脚本。

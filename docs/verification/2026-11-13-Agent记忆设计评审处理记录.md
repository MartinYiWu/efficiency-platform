## 3. 实施首期的收缩

首期唯一业务闭环：私有低风险结构化偏好保存→版本/确认→新会话精确读取→更正→忘记及抑制，连同历史安全依赖、ContextPacket/ContextBuilder、整thread禁恢复/清理、必要费用门禁和基本管理页。

项目/部门/组织共享审批、通用案例、自动提炼、向量与模型切换、通用冲突控制台后移。全Agent治理覆盖必须先完成显式启用/禁用，业务记忆能力按域逐步交付；未来行政未实际存在，不作为本次上线功能。M1不部署不会使用的向量链路，也不宣称已有自动语义摘要。

## 4. 机制核验与项目现状

已实际获取并阅读：

- [LangGraph interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts)：恢复会从interrupt所在节点开头重跑；外部副作用必须幂等。支持将授权门禁与Dispatch分离的修订。
- [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence)：Checkpoint、thread及pending写入是运行时机制，不自带source→业务派生物映射。锁定Saver版本后仍需验证实际delete_thread能力及所有存储表清理，文档不把API存在当项目已接合。
- [SQLite WAL](https://sqlite.org/wal.html)：WAL共享内存要求同机，不适合跨主机网络文件系统；第一次www域名获取超时，后从官方主域名成功获取并保存。
- [pgvector README](https://github.com/pgvector/pgvector#filtering)：ANN扫描后过滤会导致合法候选不足；iterative scan是有界改进机制，不能拿召回不足当越权证据。

项目只读核对：`persistence/paid_budget.py`的`reserve()`在BEGIN IMMEDIATE事务内校验/累计budget、scope、workload和reservation，提交后才返回；`providers/paid_http.py`在外发前consume/reserve，无法确认外发时可能保守占用调用次数，不是供应商精确计数。`configuration/paid_budget.py`路径随当前OS用户决定，因此支持部署必须固定服务身份，不能靠不同profile分账。

`orchestration/postgres_checkpoint.py`有持久适配与官方Saver工厂，但本轮未验证全入口接合/源级删除；跨授权链task累计也是新增设计门禁，不能声称现有账本已完成。R2明确在未支持时拒绝过期付费续执行，而不是借架构文档默许换预算。

公开快照URL、获取时间、SHA256见`.local-research/agent-memory-20261113/review/sources.json`、`sqlite-source-retry.json`。未联网调用供应商，未运行这些开源项目，不复用网页内容作为操作授权。

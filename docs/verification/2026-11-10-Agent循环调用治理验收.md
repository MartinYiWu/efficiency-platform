状态：本轮离线实施与验收完成，真实运行部署未执行。负责人：本轮执行代理。更新时间：2026-11-10（北京时间）。适用范围：客服Agent执行链、共用付费HTTP与SQLite单任务守卫。

关联：[实施计划](../superpowers/plans/2026-11-10-Agent循环调用治理-实施计划.md)。用户明确单次任务费用上限100元；本轮不展开价格及收费授权工作。

## 已实施行为

| 控制 | 实现及证据 |
| --- | --- |
| 任务边界 | `core/execution_control.py`固定最多60次HTTP、单逻辑操作3次HTTP、10分钟；SQLite在事务内对单任务次数/费用取原授权与60次/100000000微元中的较小值。旧授权不会被自动扩大。 |
| 成功/在途去重 | 网关按阶段、完整输入、冻结模型策略、输出类型/Schema、Prompt绑定生成摘要。并发相同操作共享一次执行；成功结果深拷贝返回；不同任务、证据或模型策略不串用。 |
| 无进展 | 连续3次重放已成功操作，返回`AGENT_NO_PROGRESS`并停止；不同证据产生相同文字结论仍视为不同有效工作。不能将此项宣称为任意改写Prompt的语义循环识别；此类不同输入仍受60次和10分钟限制。 |
| 统一尝试额度 | 同一个操作的网络重试、空响应和Schema修复共享ContextVar中的HTTP计数，修复后的输入不重置计数。已用3次时下一次在发送前拒绝，返回`AGENT_OPERATION_ATTEMPTS_EXHAUSTED`。 |
| 有限恢复 | 已知截断/结构化输出错误及输入过预算可保留原操作计数，允许现有有限恢复或可选阶段降级；鉴权、预算等致命错误不被吞掉。Schema修复仅携带受控字段位置与错误类型，不携带模型正文和不可信字段名。 |
| 冲突工作量 | 相同父证据去重；同ID不同原文拒绝；先计算完整证据对/既有批次，超过60个检查单元发送前拒绝。保持原批量契约开关，不略过必要证据对。最多8个工作者；致命失败取消并等待同组工作者。原文/覆盖验证失败仍阻断，删除冲突层通用异常重试。 |
| 终止联动 | 客服Run与调试入口绑定独立控制/总超时。取消先停止调度；迟到结果不能覆盖取消终态。HTTP排队出槽后重查停止状态，任务退出取消直接HTTP子任务、共享模型任务及实际读取者，并主动关闭未读取响应流。 |
| 费用事实 | 已发送、取消、未知用量继续保留原SQLite预留；取消客户端不能撤销供应商已经发生的费用。新上限不意味着授权已经开通，也不意味着供应商账单一定精确等于本地估算。 |

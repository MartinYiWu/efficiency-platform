# 智能客服 RAG 真实评测闭环验收

## 1. 验收范围

本轮以以下三份真实 DOCX 作为知识来源：

- `研发内部AI使用规范.docx`
- `研发团队标准规范文档.docx`
- `阿里多Agent.docx`

验收覆盖知识文档重建索引、父子切片、检索证据、引用闭包、版本绑定、评测数据集、异步评测运行、指标汇总、运行详情和管理页面。所有运行结果均来自当前开发环境中的真实 Java、Agent、MySQL、PostgreSQL + pgvector、Redis 和外部大模型接口。

## 2. 已实施能力

### 2.1 Java 服务

- 新增 RAG 评测数据集、用例、运行、单例结果的数据库迁移和持久化实现。
- 新增评测数据集维护、用例批量导入、运行发起、运行详情、历史列表和运行对比接口。
- 评测运行冻结 Agent 版本、RAG 策略版本、知识库与索引发布版本，避免运行过程中配置漂移。
- 指标覆盖执行成功率、回答模式准确率、期望事实召回、禁用事实命中、来源召回、引用合规、版本准确率、用例通过率和 P50/P95 延迟。
- 新增已发布文档重建索引接口；重建生成新的技术版本，继续复用原始文件和正常解析、向量化、发布链路。
- 修正 Markdown 转义导致的事实等价误判。

### 2.2 Agent

- 同章节、相邻的段落型父切片在父切片预算内合并，不跨已知分页边界，保证完整操作步骤不会因段落分割而缺失。
- 冲突检查对 HTML/Markdown 转义和常见强调标记做格式等价处理，避免正确引用因展示格式被误判。
- 调试运行按冻结的多个知识库索引发布版本检索，返回完整父证据、原始跨度、引用闭包和排除原因。
- 外部模型策略最终使用 `maxRetries=2`，结构化阶段输出不合法时允许受控重试，仍不合法则继续失败关闭。

### 2.3 管理前端

- 新增评测列表、数据集详情和运行详情页面。
- 支持查看数据集、用例、冻结配置、单例结果、失败原因和汇总指标。
- 菜单保持 AI 助手下的二级能力入口，没有为智能客服配置继续增加三级菜单。

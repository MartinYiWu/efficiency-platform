## 简历正文

### 企业智能体应用与治理平台（AI 效能平台）

**项目角色：项目负责人／独立全栈开发**

**技术栈：** Java 21、Spring Boot、MyBatis、Python、FastAPI、LangGraph、Vue 3、TypeScript、MySQL、PostgreSQL／pgvector、Redis、SQLite、SSE。

### 项目概述

面向企业运营生产、组织知识服务与招聘辅助决策，独立完成从产品规划、架构设计到全栈实现的智能体平台建设。采用“业务控制面＋智能体执行面”架构，构建多 Agent 协作、知识检索、记忆与上下文、规则决策、执行安全和成本核算等公共能力，承载运营助手、企业知识客服及 AI 人事助手，形成业务应用、运行治理与质量评测相结合的平台体系。

### 核心职责与项目贡献

- **平台架构与能力抽象：** 负责产品领域划分、数据模型、服务边界及核心链路设计，以 Java 承载身份权限、业务事务、配置发布和状态持久化，以 Python 承载模型推理、工具调用及图编排。建立 Agent、Strategy、Tool、Capability、Provider 分层扩展机制，隔离业务流程与模型厂商依赖，支持不同业务共享执行与治理能力；独立完成 Vue 3 前端及跨语言接口集成。

- **多智能体协同与任务交付：** 基于 LangGraph 构建 Supervisor—Specialist 协作体系，将运营计划编译为具有依赖关系的任务 DAG，实现任务准入、拓扑校验、分波调度、并发约束、预算分配与结果聚合。贯通“规划—工具执行—证据整理—反思补查—质量修复—制品交付”，落地 **8 类运营场景**，支持研究资产跨轮复用及 **3 类内容平台**的结构化生成与独立版本管理。

- **知识检索与证据可信链：** 构建查询规划、父子切片、向量／全文混合检索、RRF 融合、重排及证据组装链路，将知识问答治理延伸至适用范围、证据充分性、跨文档冲突和引用闭包。针对复杂问题拆分不充分、重排覆盖失衡及父证据二次截断进行链路优化，建立“回答—引用—原文—文档版本—索引发布”的追溯关系，支持知识不足拒答与检索过程复核。

- **统一记忆与上下文工程：** 主导跨业务记忆架构，划分会话历史、用户私有偏好与任务上下文，建立租户、用户、Agent、会话及执行级隔离模型。完成私有偏好的加密版本存储、跨会话读取、CAS 更正、幂等及并发控制，并通过隔离环境接口验证；在最终模型请求边界实施完整序列化计窗、容量准入、输出预留和来源依赖校验。同步建设遗忘撤权、Checkpoint 清理及分段摘要校验、压缩收益评估组件，推进记忆生命周期与主执行链路接合。

- **模型与规则协同的招聘决策引擎：** 独立构建岗位规则、简历解析、事实确认、人岗匹配、人才检索及面试准备流程，将模型职责限定为事实提取和逐项语义判断，由 Java 规则引擎完成硬条件校验、五维评分、覆盖门禁和分档计算。通过 UNKNOWN 状态、原文证据、冻结配置及人工复核避免缺失事实被直接判负，实现评价过程可解释、评分结果可复算；支持规则变更影响预览及无需模型调用的权重重算。

- **数据资产复用与生命周期治理：** 基于文件指纹、来源授权和保留期限实现原始解析复用，区分模型原始输出、人工修正事实及岗位匹配结果，使用不可变快照与失效标记维护数据血缘。通过 AES-GCM 加密、部门／对象级授权、限时访问和独立面试官数据投影保护招聘资料；采用可见性即时撤销与持久化 Saga，协调索引、业务记录、私有文件和缓存清理。

- **执行安全与成本控制：** 构建统一工具运行时，对工具白名单、权限、Schema、副作用、超时和输出规模执行硬校验。在客服链路实现同操作在途合并、成功结果复用、重复无进展终止和跨层共享重试额度，约束模型自主执行。设计生成、Embedding、重排共用的持久预算账本，形成“发送前原子预留—正常用量结算—未知结果保守占额—异常持久熔断”的费用控制流程，防止并发、重试及进程重启突破授权边界。

- **配置发布与质量工程：** 建设 Prompt、Agent、模型策略、RAG 策略及知识索引的版本绑定与发布机制，冻结任务配置和输入依据；配套评测集管理、异步评测、历史对比、检索快照及阶段诊断，区分执行成功与业务正确。打通 SSE 过程展示、终态持久化及跨重启历史事件重放，使问题能够沿业务任务、检索证据和模型调用逐层定位。

### 项目成果

- **完成三条业务线的平台化交付：** 将运营任务生产、企业知识问答及招聘辅助决策纳入统一应用体系，贯通任务发起、执行控制、人工介入、结果交付与历史追溯。
- **形成可复用的 AI 业务资产：** 运营研究成果可跨轮加工为多平台内容，招聘原始解析可在授权范围内复用，知识与规则采用版本化管理，支持持续迭代而不覆盖历史依据。
- **建立模型输出进入业务流程的控制机制：** 通过证据核验、确定性计算、权限校验、上下文准入和费用约束，将生成结果转化为可审阅、可复算、可追溯的业务产物。
- **形成独立完成复杂 AI 产品的研发闭环：** 覆盖产品设计、双语言后端、前端交互、数据存储、Agent 编排、评测及异常治理，完成真实服务集成与分阶段业务验证。

## 维护与面试口径

以下为项目经历的事实边界，不作为简历正文的组成部分：

- “平台化交付”描述代码、业务链路与阶段验证，不等同于生产上线、规模化使用或已取得业务收益。
- 运营与客服已有真实模型链路验收记录；HR 的接口与业务流程验证使用真实服务、数据库和隔离 Fake Provider，不代表真实候选人评价准确率或生产招聘效果。
- 记忆与上下文工程按阶段实施。私有偏好及隔离能力已有隔离环境验证；遗忘清理、恢复和完整生命周期仍需按当前实施记录确认。摘要校验与压缩收益组件不等于主链路已启用自动压缩，不能表述为完整向量记忆、自动学习或跨 Agent 共享已经上线。
- 上下文计量采用保守请求上界，不应称为供应商官方 tokenizer 的精确计数；费用结算为按核验费率进行的本地 usage 核算，不等同于供应商最终账单。
- 重复无进展识别针对相同逻辑操作的重放，不等于任意语义循环均可识别。历史终态回放不等于运行中任务可以跨重启无损续跑。
- 量化成果必须注明数据集、环境和时间范围；不补写未经验证的用户规模、节省工时、招聘准确率、成本下降比例或生产 SLA。

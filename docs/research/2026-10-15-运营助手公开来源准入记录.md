# 运营助手公开来源准入记录（2026-10-15）

## 准入边界

- 本次仅对用户已批准的公开 HTTPS 端点执行只读探测。
- 探测走 `SafeHttpTransport`、DNS 公网地址校验、IP 固定连接、TLS 证书校验、响应体大小限制和安全 XML 解析。
- 所有来源只允许保存元数据、规范 URL 和短摘录；文章正文、附件和第三方页面不在准入范围内。
- 来源可用和内容真实是两个不同结论。热点事实仍需引用闭包支持，平台热度不能单独证明事实。

## 许可与使用约束

- OpenAI：只读取其公开 RSS，不复刻或保存文章全文；证据入口为 [OpenAI News RSS](https://openai.com/news/rss.xml) 与 [OpenAI policies](https://openai.com/policies/)。
- Hugging Face：只读取其公开博客 RSS 的标题、时间、URL 和短摘录；内容权利仍受发布者及其条款约束，证据入口为 [Hugging Face Blog RSS](https://huggingface.co/blog/feed.xml) 与 [Hugging Face Terms of Service](https://huggingface.co/terms-of-service)。
- GitHub Blog：官方 RSS 端点存在，但本次没有通过系统安全传输边界，因此保持未注册、未启用。

## 验收期间发现并修复的问题

1. 外部模型服务长时间只返回保活或超时。对引用已有研究条目的成稿增加了仅使用已验证证据的确定性降级路径，避免编造事实；模型服务恢复后仍可使用模型路径。
2. 研究来源数量、正文获取和 Hacker News 调用预算导致有效条目不足。已改为校验真实来源、限制正文抓取、使用官方 Hacker News API，并保留“数量不足不虚构补齐”的行为。
3. Java 在保存平台制品时使用 `Collectors.toMap` 处理可空字段，真实 SSE 回调触发空值异常。已改为显式构造 `LinkedHashMap`，真实调用复验通过。
4. Agent 的 SSE 保活帧没有数据时，Java 客户端曾把空数据交给下游。已过滤空帧，真实长连接复验通过。
5. 预期的业务拒绝最初被记录为错误日志。已区分请求拒绝和运行时异常，复验为 `WARNING`。

## 真实调用中发现并修复的问题

1. 缺参追问只通过 SSE 返回、Java 未持久化：在 `clarification_required` 投影时保存 assistant 消息，随后用真实接口重放通过。
2. 今日头条自然语言平台描述被严格等值匹配拒绝：增加唯一别名归一化，仍对未知平台失败关闭。
3. 引用研究制品时，研究制品的 `platform=research` 覆盖用户明确指定的今日头条：改为优先保留显式目标平台，只在没有目标平台且引用为受支持内容平台时继承。
4. Hacker News 标题字段可能为空，mypy 发现字符串类型缺口：增加候选标题后备，相关抓取用例和静态类型检查通过。
5. 本地真实研究的输出预算调整后，集成用例仍断言旧的 8000 token 预留值：按当前 64000 token 总预算修正为 16000，随后全量回归通过。
6. 历史日志保留了两次今日头条失败尝试的 `stream_error` INFO；修复后的最终 run `run-79bbff4597184da097f3a6350444e377` 中外部模型请求均返回 HTTP 200，Agent 终态为 `succeeded`，Java 完成事件投影与制品持久化。没有删除或改写历史失败日志。

# 成本保护业务链路与交付复核

- 状态：用户已授权按下一步三项工作制定计划并实施。
- 日期：2026-11-03；负责人：本轮实施者。
- 范围：本地跨语言链路验收、当前改动分类交付复核、真实验收只读准备。

复用生产Java HTTP/SSE客户端、客服应用服务/事件投影和Python客服运行/Graph/预算HTTP守卫。测试数据、知识仓储和上游模型使用明确的本地fixture，SQLite仅临时测试总账。Java与Agent之间以及Agent与测试上游走loopback真实HTTP，不启动现有主目录服务、不使用共享业务数据库或付费供应商。

链路覆盖正常结算、次数/token/费用耗尽、重试、取消及并发，核对Java投影后的Run/助手消息状态、公开错误码与SSE终态，以及SQLite预留/实际/unknown一致。前端利用公开SSE/消息契约验证预算错误可见、无伪完成；如实际行为有缺陷先复现再最小修改，不新增预算管理页面或改变登录/身份流程。

交付整理只生成分类文件清单、风险/回滚说明和验证证据：格式化、试用流程、成本保护、未启用性能候选分开审阅；本轮不主动提交推送，不丢弃既有改动。用户配置与原未跟踪计划排除交付范围，原始验收数据与本机账本不入库。

真实验收准备为本机无网络readiness命令：核验完整预算计划/冻结价格/期限和对应最多三道代表问题，生成可审阅报告；不授权、不派发、不修改真实总账。预算未明确、价格未核实、账户侧消费上限未确认时返回BLOCKED，并列出所缺项。示例仍为全0未核实，不能一键开通；不得查询密钥或假报实际账单对照。真正收费执行仍需用户明确预算后单独授权。

本轮测试可以临时启动仅loopback的测试进程，结束必须关闭并核验，无残留前后端/Agent服务；外部付费调用数必须0。已有其他项目的5173不触碰。

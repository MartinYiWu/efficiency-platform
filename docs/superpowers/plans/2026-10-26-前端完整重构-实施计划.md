# 前端完整重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按已确认的“企业控制台”设计稿重构现有前端全部路由的导航、页面结构、视觉和窄屏布局。

**Architecture:** 保留 React Router 路径、现有 API 客户端和业务状态；重写平台外壳为横向一级导航与按模块变化的局部导航。知识中心、AI 管理、对话和人事页面分别采用列表/详情、对象工作区、消息阅读区、业务流程工作台的结构。页面只呈现真实接口或现有前端支持的操作。

**Tech Stack:** React 19、TypeScript 6、Ant Design 6、CSS Modules、Vite 6、Vitest、Playwright。

## Global Constraints

- 设计依据：`docs/superpowers/specs/2026-10-26-前端完整重构-设计.md` 与 `docs/design/frontend-redesign-2026-10-26/` 中的五张概念稿。
- 保持现有全部 URL、Java/Agent 接口、真实字段含义、客服会话删除与引用流程。
- 图片中的日期、人数、回答、额外分类和不受接口支持的按钮仅为示例，不能写入业务数据或伪装成可用操作。
- 当前未实现登录，页面不再硬编码虚构姓名或角色。
- 页面本身在 1440、1024、390px 视口不得横向溢出；宽表格仅在自身容器内滚动。
- 对真实接口结果和浏览器错误进行观察；不能以构造测试数据替代真实页面验收。

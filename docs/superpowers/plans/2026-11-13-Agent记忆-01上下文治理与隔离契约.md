## D02：框架中立契约与隔离值类型

依赖：D01。新增Agent：`src/efficiency_platform_agent/core/context_control.py`、`core/memory.py`、`core/memory_ports.py`、`contracts/context_control.py`、`contracts/memory.py`；修改`context/contracts.py`、`agents/validation.py`；新增测试`tests/unit/context/test_context_contracts.py`、`tests/unit/memory/test_scope_contracts.py`。

产出完整接口：

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class ConversationScope:
    tenant_id: str
    user_id: str
    domain: str
    top_level_agent_id: str
    session_kind: str
    session_id: str | None

    @property
    def history_key(self) -> tuple[str, str, str, str, str] | None:
        if self.session_kind == "TASK_ONLY":
            if self.session_id is not None:
                raise ValueError("SCOPE_SESSION_INVALID")
            return None
        if self.session_kind != "CONVERSATION" or not self.session_id:
            raise ValueError("SCOPE_SESSION_REQUIRED")
        return (self.tenant_id, self.user_id, self.domain,
                self.top_level_agent_id, self.session_id)
```

同文件补入构造校验：所有非可选ID非空且≤128字符、域/Agent来自catalog，reject空字符串。`ExecutionScope`组合ConversationScope与task_id/execution_id/subtask_id/purpose；core不importPydantic或其他层。

其余值类型一次声明：ModelCapacity(W/I/max_output/tokenizer_ref/serialization_ref/version/reasoning_rule)、WindowLimits(W/I/O/S/P)、TokenMeasurement(total_upper_bound,by_component,method,verified)、WindowDecision(H_ctx,T,F,status)、SourceDependency(source_type/id/version/epochs)、PreparedContext(request,manifest)、ContextManifest字段按协议§11；MemoryPolicy/MemoryContextPacket/MemoryProposal/MemoryReference按总设计。边界Pydantic模型`extra=forbid`并与core显式转换，不把预算/权限放进模型可修改字段。

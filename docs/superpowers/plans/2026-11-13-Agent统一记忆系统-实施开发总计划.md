# Agent统一记忆系统实施开发总计划

> 执行者：逐任务使用executing-plans技能；需要独立实现/复审时按明确授权及适用技能使用subagent-driven-development。所有步骤用复选框跟踪；已启动实施，逐任务按证据更新状态。

**目标：** 按租户—用户—顶层业务Agent—会话—任务隔离，交付受窗口/费用约束、可跨会话使用且可更正/遗忘的Agent统一记忆，逐步开放摘要、语义召回和显式共享。

**架构：** Java AI Hub拥有记忆、消息、权限、确认和删除；Python负责当前节点上下文、候选提炼及受控索引，LangGraph是唯一运行时。MySQL保存权威业务/Agent运行事实，PG保存Checkpoint及后续可重建索引，Redis为可丢弃加速，固定SQLite管付费；不增加Java模块、微服务或第二套Agent框架。

**技术：** Java21/Spring Boot3/MyBatis/MySQL；Python3.13/LangGraph/Pydantic/现有Provider；PostgreSQL/pgvector；Vue3/TypeScript/Zod/Ant Design Vue；现有pytest/Ruff/mypy、JUnit/ArchUnit、Vitest/Playwright。

**状态：** 执行中；D01—D09通过，D10隔离迁移通过而共享迁移仍1419阻塞；D11—D16受支持组件及独立复审通过，D17真实Java→Agent→MySQL/PG的运营/客服遗忘与8范围16会话管理矩阵通过，恢复旧数据读取屏障红绿及原功能回归通过，仍待在途网络撤销、恢复与阶段最终门禁。D18—D20部分独立组件通过，M2持久化/CAS/主流程及后续阶段未完成、未启用；逐项状态见本机progress及[私有记忆验收记录](../../verification/Agent私有记忆闭环验收记录.md)。创建日期：2026-11-13；更新：2026-11-17，北京时间。负责人：当前执行者；架构/产品裁决由项目负责人评审。

依据：[总设计R4](../specs/2026-11-13-全项目Agent统一记忆系统-设计方案.md)、[上下文执行协议](../specs/2026-11-13-上下文预算与压缩执行协议.md)、[评审整合记录](../../verification/2026-11-13-Agent记忆参考方案整合记录.md)。本次用户进一步确认的用户/Agent/会话边界已写入总设计§8.1。

## 全局约束

- 实施已获授权；按任务最小修改并先在隔离依赖验收。未经有效价格/预算授权不调用真实模型/Embedding/rerank；计划命令不自动构成已运行证据。
- 项目禁止Git初始化、提交、推送、重置及Git diff；每任务改前快照、文件差异、SHA256及进度账本替代版本审查，不创建Git worktree。
- 单任务100元/60次实际付费HTTP、每execution最长10分钟、每逻辑操作最多3次尝试，更严格有效授权优先；无核实价格及有效预算真实请求发送前拒绝。402/累计429持久熔断；换run/job/进程/预算ID不清零。
- 跨授权task累计在D24实现并验证前，过期后付费续执行必须CONTINUATION_AUTH_UNSUPPORTED；不能解封旧stopped记录。CPU确认记忆不需要模型授权。
- Java只经AiInvokeFacade调用Agent，Python不回调Java/直写Java表；前端不直连Agent。core只依赖core；持久化只能依赖既有准入层，不为省事放宽AST/ArchUnit。
- 正常session绑定tenant/user/domain/top_level_agent；专家继承受控子任务切片。TASK_ONLY不读聊天历史，不把null session合成共享桶。切顶层Agent默认新会话。
- 默认私有偏好限定当前顶层Agent；同Agent跨会话只复用已确认字段。跨Agent仅显式允许的语言/长度/格式白名单，不分享原文/摘要/业务材料。跨用户需后续项目/组织授权。
- 记忆字段、状态、遗忘/抑制、完整安全依赖及整thread删除按总设计；窗口/阈值/投影/摘要/Manifest按独立协议，不在任务里另设矛盾数值。
- 先行为红测、确认失败原因、最小实现、定向绿测；每阶段冻结后按范围做一次全量。Fake只能在Provider等真实外部边界，不用Mock服务层伪造真实HTTP通过。
- SQL唯一目录沿所属工程治理；Java从执行时最大V号顺延，当前不预占版本、不重写已执行迁移；Agent脚本按bootstrap新主题目录。每组有precheck/up/verify/rollback。
- 共享库迁移须先只读预检、展示影响/SQL/回滚并核实该次授权；既有HR数据库授权不擅自扩大为本记忆模块DDL。真实授权是执行时最终门禁，先完成可审阅脚本和隔离库演练。

Java MemoryJob为记忆业务任务权威；Agent的manifest/lease/操作回执只记录技术执行，不能另建同一MemoryJob的可独立修改业务状态。摘要/索引返回Java后由本地CAS推进；Outbox及任务租约不代表Provider未发，未知状态沿原回执与费用预留阻断。

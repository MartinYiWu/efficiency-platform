# 全站前端视觉升级实施计划

**目标：** 统一 48 条前端路由的布局、排版、状态呈现与窄屏行为，不改业务接口。

**架构：** 以 `AppProviders` 的 Ant Design 主题、`tokens.css`、`PlatformShell` 和通用页面容器作为全站基础。各页面保留现有组件，仅按工作台、列表、详情/表单、对话四类统一布局；清除 CSS module 中跨页面生效的裸标签选择器。

**技术栈：** React、TypeScript、Ant Design、CSS Modules、Vite、Playwright。

## 任务 1：基础视觉与样式隔离

**文件：** `src/app/providers/AppProviders.tsx`、`src/app/styles/tokens.css`、`src/app/styles/global.css`、`src/widgets/hrAssistantShell/HrAssistantShell.module.css`、`src/shared/ui/PageContainer/PageContainer.module.css`；清理 `src/pages/hr-assistant/{matching,resumes,settings}` 中裸 `main`、`aside`、`footer` 选择器。

1. 记录现有 1440×900 和 390×844 的框架截图、溢出数据。
2. 统一颜色、圆角、字体与控件高度 token；统一左导航、顶栏、内容画布、页面标题和操作区。
3. 为页面私有标签样式增加容器类作用域；移除 `global.css` 的裸 `main` 布局规则。
4. 用浏览器复核智能客服、岗位管理与设置页不再互相串样式。

## 任务 2：管理类页面

**文件：** `src/pages/ai-center/AiCenter.module.css`、`src/pages/ai-center/{AgentListPage,AgentDetailPage,PromptManagementPage,ModelPolicyPage,RagPolicyPage,RagDebugPage,RunListPage,RunReplayPage,FeedbackPage,RagEvaluationListPage,RagEvaluationDatasetPage,RagEvaluationRunPage}.tsx`、`src/pages/knowledge-center/KnowledgeCenter.module.css`、`src/pages/knowledge-center/{KnowledgeBaseListPage,KnowledgeBaseDetailPage,KnowledgeDocumentPage,KnowledgeImportPage}.tsx`。

1. 统一标题、说明、主操作、筛选和内容的左边界与垂直间距。
2. 调整卡片信息层级、长标题和空状态；将可见原始状态/知识类型/可见范围映射为中文。
3. 使双栏/三栏调试界面在窄屏按内容优先级依次排列，表格仅自身横向滚动。
4. 截图检查知识中心、Agent 管理、Prompt、RAG 调试、运行列表与引用抽屉。

## 任务 3：人事助手页面

**文件：** `src/pages/hr-assistant/workbench/HrWorkbenchPage.module.css`；`positions`、`resumes`、`matching`、`talent`、`interviews`、`settings`、`module-entry` 下现有页面 CSS modules 与必要的页面组件。

1. 工作台指标卡和快捷入口等高对齐。
2. 职位、简历、匹配、人才列表的标题/筛选/表格采用统一布局；固定操作列可读性，避免页面级水平溢出。
3. 详情与表单页统一主信息/分组/操作结构，缩小无意义留白；校正窄屏列数。
4. 按页面类型抽样检查 1440 与 390 宽度截图，并检查原有交互入口仍在。

## 任务 4：对话页

**文件：** `src/pages/operations-assistant/chat/OperationsChatPage.module.css`、`src/pages/hr-assistant/chat/HrChatPage.module.css`、`src/pages/customer-service/CustomerServiceChatPage.module.css`，及对应组件必要的语义调整。

1. 统一标题、头像、消息宽度、引用区和输入区轴线；保留各助手的业务能力与操作。
2. 检查长回答、流式进度、空会话及窄屏的可读性。

## 任务 5：全路由验收

1. 从 `AppRouter.tsx` 提取全部 48 条路由，浏览器批量打开并记录页面错误、水平溢出与截图。
2. 对真实数据页面逐项目视复核；仅修复视觉与排版问题，不更改业务行为。
3. 运行 `pnpm typecheck`、`pnpm lint`、`pnpm build` 和相关既有测试。
4. 检查 `git diff --check` 与本地配置不变；合并到 `main` 并推送。

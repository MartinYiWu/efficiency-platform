# Vue 前端开发规范与约束（草案）

本文描述独立Vue工程的完整实施规范。原React工程保持只读，正式入口尚未据此切换。优先级：用户当前明确要求 → 适用AGENTS.md → 本规范 → 架构草案 → 既有代码风格。

## 运行时与依赖

Node.js需满足package.json engines（20.18至21之前，或22及以上），pnpm 10。锁文件与package.json必须一致。版本以实际锁文件为准：Vue 3.5、Router 4、Pinia 3、Ant Design Vue 4、图标Vue版7、Vite6、Vitest4。

只使用一套Vue运行时、路由和基础UI。禁止将React、React Router、React Ant Design、React Markdown或TanStack React Query带入生产入口。现有依赖能满足时不添加新库；新增依赖需说明用途、包体积、许可证、维护情况与移除成本。旧工程展示代码可参考，旧业务服务与认证不可直接复用。

## 目录与命名

`app`装配；`pages`路由页编排；`widgets`复合业务区块；`features`用户动作和异步流程；`entities`实体/DTO/Zod/展示转换；`shared`无业务归属基础设施。禁止shared向上依赖、实体导入页面。模块公开入口优先用index.ts；不要为一次性流程创建万能抽象或空目录。

组件为PascalCase.vue，script setup使用TypeScript；composable以use开头，纯TS文件按主导出命名。页面中文文案，标识及URL维持英文。避免any、宽泛类型断言和未经验证的非空断言；外部响应先按既有契约校验。

## 状态与生命周期

组件本地交互用ref/reactive，派生值用computed；归约器模式保留纯函数并测试。跨页面本地偏好可用Pinia，不复制后端数据建立第二真源。浅引用仅用于通过整体替换更新的状态，禁止依赖深层突变触发渲染。

每个异步流程明确对象ID、请求世代、AbortController与终态。卸载/切换时世代失效，清定时器和监听器，停止SSE。异步请求返回前后都要核当前世代；过期finally也不得覆盖新对象。POST提交必须去重；重连、轮询、历史恢复不能重复提交生成。取消前Run未创建时记录当前提交的取消意图，Run到达后只取消对应Run。恢复历史结束与恢复流运行分开，不让取消后遗留永久busy。

客服和运营是两套协议：客服afterSequence、事件序号和大写状态；运营`run.stream.event/1` envelope及小写状态。不得互换事件解析器。保留分块、去重、Last-Event-ID、断线续读、终态与失败消息；缺失历史事实显示未记录，不按当前配置重算。

## 接口与安全

| 模块         | 当前入口                  |
| ------------ | ------------------------- |
| 客服         | `/api/customer-service/*` |
| 运营         | `/api/operations/*`       |
| 知识         | `/api/knowledge/*`        |
| AI管理与评测 | `/api/aihub/*`            |

当前模块成功信封为`code === 'SUCCESS'`。保留Zod、响应错误码、预算拒绝及可用traceId。不得接旧`/v1`或`code===200`契约。使用既有API层，不在页面裸请求业务接口；保留原有fetch或Axios，不为统一形式改变语义。

浏览器配置只用VITE_变量，不能放后端密钥、个人信息或Token。日志不输出提示词、凭证与敏感业务载荷。Markdown禁止HTML与危险链接，外链noopener/noreferrer。

## 视觉与可访问性

复用确认的v1令牌、白侧栏、56px顶栏、8px圆角和轻阴影。新增业务布局用scoped/CSS Modules，避免无作用域main/header/table选择器污染App Shell。原页面字段、动作、空态、错误态、loading及禁用理由不可因视觉迁移丢失。

1440、1024、390px验证导航、卡片、抽屉、表格、消息长文和输入。交互用button/link等语义元素，提供名称、焦点和aria状态；不能仅颜色表示结果。流式内容不抢夺用户阅读位置；后续动作焦点应回到有效控件。

## 测试与付费边界

测试按纯函数/契约、Vue组件/composable、Playwright分层。使用Vue Testing Library或Vue Test Utils和真实Antd；Mock外部边界，不能以全局stub掩盖控件行为。覆盖错误、预算拒绝、取消、卸载、切换竞争、刷新恢复、重复事件、终态和冻结证据。

默认全部离线，未MockAPI必须失败。真实生成/Embedding/rerank必须先有用户真实预算，并走统一付费守卫和固定SQLite总账；禁裸curl/SDK、另建账本、预算自动续期。不得把fixture通过称为真实服务验证。

交付门禁：

```powershell
pnpm format
pnpm lint
pnpm typecheck
pnpm test:coverage
pnpm build
pnpm test:e2e
```

先定向验证，修复后最终全量一次。测试失败应查根因；不删除断言或排除业务目录。构建与类型通过不能替代运行交互验收。报告命令、结果、范围及未验证项；截图需同视口同状态对照旧版视觉、对照当前业务分别判断。

## 文档与交付

架构、依赖、环境变量或门禁改变同步AGENTS、规范、架构、README。保存功能与URL迁移记录。人事本地演示继续标注演示，不描述为已接真实人事后端。原工程切换/删除/移动需单独授权并保存可恢复副本；当前草案不执行此类操作。

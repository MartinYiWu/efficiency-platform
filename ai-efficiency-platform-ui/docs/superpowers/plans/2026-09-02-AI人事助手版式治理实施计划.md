# AI 人事助手版式治理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 消除 AI 人事助手页面的无效留白、卡片割裂、操作不可达与伪分页，使 PAGE-01、PAGE-08 至 PAGE-21 在桌面、平板和手机端形成一致、紧凑且可操作的版式。

**Architecture:** 保留既有 React Router、Ant Design 和 CSS Modules。新增只服务于页面骨架的共享布局类，不改变业务字段、路由、分档颜色或已确认交互；页面按工作台、数据列表、三栏工作区、表单/进度四类模板收敛。桌面优先保证主任务区宽度，窄屏时将辅助栏下沉；主操作固定在标题区或粘性操作条，只有表格、日志和弹窗内容可局部滚动。

**Tech Stack:** React 19、TypeScript、Ant Design 6、CSS Modules、Vitest、React Testing Library、Playwright。

## 全局约束

- 不新增运行时依赖，不新增未在规格中定义的业务入口。
- 桌面内容区使用 `max-width: 1600px` 与自适应内边距；不得用固定页面宽度制造横向滚动。
- 主操作必须在初始视口或粘性操作条内可达；禁止只放在长页底部。
- 数据列表必须使用实际 `page`、`pageSize` 与切片数据渲染；页码、总数和每页条数不能是静态文案。
- 大宽内容仅允许在 `.tableScroll`、日志容器或模态内容区内部横向/纵向滚动。
- 每个改动页面须在 1440px、1024px、390px 下验证无页面级横向溢出，并保留关键操作截图记录。
- 当前目录不是 Git 仓库；不提交、不重置、不清理文件。

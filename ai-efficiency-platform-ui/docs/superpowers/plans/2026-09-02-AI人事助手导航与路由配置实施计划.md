# AI人事助手导航与路由配置实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 AI 人事助手左侧菜单在桌面和移动抽屉中均可导航，且所有一级模块都有稳定入口与正确高亮。

**Architecture:** 在 `widgets/hrAssistantShell` 中维护唯一的菜单定义（菜单 key、标题、默认路由和图标），由菜单点击统一驱动 React Router。新增一个仅用于未开发模块的模块入口页；后续完成真实页面时直接替换该路由元素，不改变菜单与链接。

**Tech Stack:** React 19、React Router 7、Ant Design 6、Vitest、Testing Library。

## 全局约束

- 不增加运行时依赖。
- 菜单、面包屑和选中状态以当前路由为唯一事实来源。
- 已开发岗位模块保留现有细分路由；未开发模块不允许落入 404。
- 使用 CSS Modules，不使用行内静态样式。

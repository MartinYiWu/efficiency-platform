# AI 内容运营助手专业化交付体验实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 保留现有“AI 内容运营助手”品牌、导航和对话入口，将 Deliverable V2 呈现为易读的热点榜、平台内容、行动计划、诊断和复盘，并提供来源折叠、可解释降级和安全后续动作。

**Architecture:** DTO 在 `entities/operation-deliverable` 通过 Zod 严格校验并映射为判别联合 ViewModel；`widgets/operation-delivery` 按交付类型渲染；现有 `features/operation-chat` 继续管理请求、SSE、取消和消息状态，只增加阶段状态与双版本集合。页面只负责编排，不直接解释原始 JSON 或调用 API。

**Tech Stack:** React 19、TypeScript strict、Vite 6、Ant Design 6、CSS Modules、Zod 4、React Markdown 10、Vitest、React Testing Library、Playwright。

## Global Constraints

- 本目录永久不是 Git 仓库；不得初始化、提交、推送、重置或声称 Git 审查，每个任务使用文件清单、测试输出和进度账本留证。
- 新行为必须执行失败测试 → 观察红灯 → 最小实现 → 观察绿灯；不得只验证 CSS 类名或第三方组件内部结构。
- 保持 `pages → widgets → features → entities → shared` 单向依赖；同层跨模块只能经 `index.ts`。
- 只使用现有依赖；不得新增 UI 库、状态库、Markdown、聊天、富文本、拖拽、Tailwind、Moment、Lodash 或 jQuery。
- Ant Design 是唯一基础 UI 与图标体系；布局使用 CSS Modules，跨页面 Token 才能进入 `src/app/styles/tokens.css`。
- V1 必须继续渲染；V2 解析失败关闭，不根据字段形状猜版本，不渲染原始 JSON。
- 原始 HTML 必须禁用；外链使用 `target="_blank"` 和 `rel="noopener noreferrer"` 或 `noreferrer`。
- 后续动作只能把 Agent 已校验的 `intent_patch` 转成下一轮可见消息；不得自动发布、上传、授权或调用未知 Tool。
- 页面需在 1440px、1024px、390px 验证，且键盘、焦点、标题层级和状态语义成立。
- 每个任务完成后更新 `docs/superpowers/progress/2026-09-17-AI内容运营助手专业化交付体验-进度.md`。

- [ ] **Step 4: 使用 Zod 建立严格 Schema 和版本分派**

所有对象使用 `.strict()`，URL 使用：

```ts
const httpsUrlSchema = z
  .url()
  .refine((value) => new URL(value).protocol === 'https:', '只允许 HTTPS 来源');

export function parseDeliverableSet(value: unknown): DeliverableSetDto | null {
  if (!value || typeof value !== 'object' || !('contract_version' in value)) return null;
  const version = (value as { contract_version?: unknown }).contract_version;
  const result =
    version === 'deliverable-set/1'
      ? deliverableSetV1Schema.safeParse(value)
      : version === 'deliverable-set/2'
        ? deliverableSetV2Schema.safeParse(value)
        : null;
  return result?.success ? result.data : null;
}
```

V2 `content` 使用 `z.discriminatedUnion('kind', [rankedDigestContentV2Schema, platformContentV2Schema, actionPlanContentV2Schema, diagnosisContentV2Schema, retrospectiveContentV2Schema])`，V2 顶层交付物使用 `z.discriminatedUnion('deliverable_kind', [rankedDigestDeliverableV2Schema, platformContentDeliverableV2Schema, actionPlanDeliverableV2Schema, diagnosisDeliverableV2Schema, retrospectiveDeliverableV2Schema])`；每个顶层分支还要校验其 `content.kind` 与 `deliverable_kind` 一致。数组最大长度、正文最大长度和枚举应与 Agent Pydantic Schema 对齐。

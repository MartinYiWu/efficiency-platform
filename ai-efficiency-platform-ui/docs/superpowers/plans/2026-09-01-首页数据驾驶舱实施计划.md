# 首页数据驾驶舱实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在根路由交付具备页面壳、指标、趋势和待办状态的数据驾驶舱首页。

**Architecture:** 使用 `widgets/appShell` 提供全局顶栏和导航，`pages/dashboard` 只编排页面。`entities/dashboardOverview` 提供本地 ViewModel 与将来接口替换边界，图表封装于 `shared/ui/Chart`，不在页面直接管理 ECharts 实例。

**Tech Stack:** React 19、TypeScript、Ant Design、React Router、ECharts、Vitest、React Testing Library、Playwright。

## 全局约束

- 不开发后端接口、认证、真实统计口径、数据详情页或通知中心。
- 首页远端数据未来只可通过 TanStack Query 进入实体层；当前本地演示数据不得作为生产接口失败兜底。
- `pages → widgets → entities → shared` 单向依赖；页面不得直接调用 Axios 或 ECharts。
- 桌面端侧栏 240px、顶栏 56px、主内容最大宽度 1440px；最小页面宽度 320px。
- 响应式断点：1280px、1024px、768px；所有导航通过键盘可聚焦。
- 先写失败测试，再写最小实现；不引入白名单以外的生产依赖。

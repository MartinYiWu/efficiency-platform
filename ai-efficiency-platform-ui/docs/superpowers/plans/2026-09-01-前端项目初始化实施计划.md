# 前端项目初始化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可启动、可测试、受依赖白名单约束的 React 单体前端项目骨架。

**Architecture:** Vite 提供静态 SPA 构建；`app` 统一装配路由、Ant Design 和 TanStack Query；业务代码未来遵循 `pages → widgets → features → entities → shared` 单向边界。初始化仅实现首页、404 页、环境配置读取及全局组件容器。

**Tech Stack:** React 19、TypeScript、Vite、React Router、Ant Design、TanStack Query、Axios、Zod、Vitest、React Testing Library、MSW、Playwright。

## 全局约束

- Node.js 20.18+；pnpm 10+；包管理器必须锁定 pnpm。
- 只可安装架构设计文档列出的白名单依赖。
- TypeScript 必须开启严格模式；源代码不得使用 `any`。
- 生产代码遵循先测试失败、再最小实现、最后验证通过的顺序。
- 初始化阶段不创建业务模块、接口、身份认证或模拟业务数据。

# Vue 前端架构

## 决策与边界

`ai-efficiency-platform-ui` 构建单一 Vue SPA。参考旧项目布局和展示结构，业务协议以当前React工程为基线。Vue生产入口不混跑React；原 React 工程作为本机回退副本保留，正式切换前后验证单独记录。

技术栈：Vue3.5 Composition API/script setup、Router4懒加载、Pinia3、Ant Design Vue4、Vue图标7、TypeScript严格检查、Vite6、pnpm10。markdown-it经共享安全组件渲染，禁止原始HTML和危险URL。保留纯TS契约、API、SSE与归约器。

## 分层

```text
app       → 启动、路由、Pinia、Antd、主题和全局v1样式
pages     → 路由参数、页面与业务组件编排
widgets   → 运营交付等复合业务视图
features  → 客服/运营流、知识上传、AI管理等用户动作
entities  → Zod契约、实体类型、DTO映射
shared    → 安全Markdown和无业务基础设施
```

业务依赖向下；不在app保存生成状态，不在shared实现领域协议，不添加第二UI或远端缓存框架。Pinia用于跨页偏好，页面状态由composable或本地ref持有。

## 数据与状态路径

客服：`/api/customer-service` → Zod → composable →消息/引用/进度组件。恢复消息与timeline后从lastEventSequence续流；run终态决定反馈和回答显示。

运营：`/api/operations` → API映射 →纯messageReducer → composable →消息/交付物。URL conversationId保留刷新恢复；stream envelope固定`run.stream.event/1`；制品接口负责复制/预览/下载，不让恢复再次提交生成。

知识：`/api/knowledge` → Zod实体 →上传/导入/处理任务功能 →列表、知识库、文档与导入页面。启用、READY发布、PUBLISHED索引与证据模式以当前契约为准。

AI管理：`/api/aihub` → Zod →Agent/Prompt/策略/调试/评测/回放。版本与Release证据只读展示冻结绑定；历史缺失字段不按当前策略重算；用例等价表述仅保留原事实仍存在的绑定。

人事继续既有本地演示数据与页面动作，本次不新增人事后端。

## 异步隔离

世代、对象ID、controller和requestId共同界定异步结果有效性。切对象或卸载立即失效；每次await后重新验证。停止区分提交中与Run运行中，不能复用旧runId。历史加载完成后释放恢复锁；运行中的恢复订阅仍可取消。重连只续读，禁止重发POST。错误与预算拒绝原样反馈，不能自动授权或加预算。

## UI与验证

旧版v1令牌和布局类全局共享，业务样式隔离；组件具备加载、空、错误、禁用状态及键盘可访问性。多视口核验1440/1024/390；表格滚动局部化。

离线门禁为Vitest/Vue Testing Library/Vue Test Utils和Playwright fixture。默认阻断未拦截API。真实付费服务不在迁移验收授权内。交付执行格式、lint、类型、覆盖率、构建和离线E2E；证据不足明确未验证，不以构建成功替代业务验收。

# 首页 Signal Board 响应式重构设计

## 目标

将当前“侧栏、顶栏、内容区相互割裂且页面松散”的首页，重构为紧凑、连续、自适应的 Signal Board 工作驾驶舱。视觉采用深色结构导航与浅色内容画布；信息优先级为“当前关键工作 → 关键指标 → 工作节奏与待办”。

本次只重构前端视觉结构、页面布局和演示数据呈现；不接入后端接口、认证、真实统计、详情页或新业务功能。

## 布局系统

首页由一个 `AppShell` Grid 管理，不把侧栏与内容区作为彼此独立的画面。

```text
AppShell
├─ SideNavigation
│  ├─ 平台标识
│  ├─ 工作区导航
│  └─ 帮助入口
└─ Workspace
   ├─ TopBar（面包屑、搜索入口、通知、用户）
   └─ DashboardPage
      ├─ GreetingHeader（问候、今日工作摘要、主操作）
      ├─ MetricGrid
      └─ DashboardGrid
         ├─ WorkRhythmPanel
         └─ PriorityTasksPanel
```

### 宽屏（≥1280px）

- Shell 左列为 224px 深色导航，右列为自适应主区；主区不使用造成空白的固定居中最大宽度。
- 顶栏高度 58px，和主区共享水平内边距 28px。
- 内容区上、左、右内边距 28px，模块间距 12px，标题区垂直间距 16px。
- 指标为 4 列等宽网格；下方内容采用 8:4 栅格，趋势占 2/3，待办占 1/3。
- 卡片仅用于承载一个信息组：10px 圆角、1px 浅边框，无默认悬浮阴影。

### 中屏（768px–1279px）

- 导航收为 56px 图标栏，保留 Tooltip 与键盘可访问名称。
- 主区内边距降为 20px；指标网格变为 2 列。
- 趋势与待办上下排列，保持各自完整宽度；不压缩成不可阅读的双栏。

### 窄屏（<768px）

- 导航隐藏为受控抽屉，顶栏提供菜单按钮。
- 主区内边距 16px，标题、重点任务、指标、趋势、待办按单列呈现。
- 首屏优先展示“优先处理”与两个最重要指标；其余内容自然向下延伸，不通过缩小字体或横向挤压保留桌面结构。

## 视觉与信息层级

- 导航背景 `#121B2B`；当前导航项使用低饱和蓝色块 `#263D63`，不以高亮边框制造割裂。
- 主区背景 `#F5F7FB`；卡片白色，边框 `#E2E8F2`；正文与辅助文字按 `#15233A`、`#7D8B9F` 分级。
- 主操作使用 `#3369E7`；正向趋势使用 `#229B6B`；颜色只表达状态，不承担唯一语义。
- 首页标题改为带情境的问候和关键摘要；去除冗余面包屑层级在标题区的重复出现。
- 指标卡使用 108px 左右的紧凑高度；每张卡片固定“标签 → 主值 → 变化”三层信息。
- 趋势模块显示 7 天柱状图、时间范围和分析入口；待办模块显示标题、截止时间、来源与紧急标签。

## 组件边界

| 组件                   | 层级     | 职责                                         |
| ---------------------- | -------- | -------------------------------------------- |
| `AppShell`             | widgets  | 响应式 Shell、导航收缩状态、顶栏与内容区结构 |
| `SideNavigation`       | widgets  | 导航呈现与当前项状态，不处理权限             |
| `TopBar`               | widgets  | 全局操作入口，不读取驾驶舱数据               |
| `DashboardHeader`      | widgets  | 问候、工作摘要和主操作                       |
| `MetricGrid`           | widgets  | 演示指标的紧凑卡片呈现                       |
| `EfficiencyTrendPanel` | widgets  | 异步图表、摘要和空状态                       |
| `PriorityTasksPanel`   | widgets  | 待办的优先级呈现和空状态                     |
| `dashboardOverview`    | entities | ViewModel 与未来 Query 接入边界              |

保留既有的 `pages → widgets → entities → shared` 单向依赖。页面不得直接依赖 ECharts 或 Axios；图表继续经 `shared/ui/Chart` 懒加载。

## 验收标准

1. 在 1440px、1024px、390px 三个视口中，侧栏、顶栏与内容区属于连续 Shell，不出现无意义的大面积留白。
2. 宽屏首屏可同时看见问候标题、四项指标与趋势/待办模块的主要内容。
3. 宽屏、中屏、窄屏分别采用 4 列、2 列、1 列指标布局；内容面板不会在中屏保持拥挤双栏。
4. 导航在中屏提供图标与可访问名称，在窄屏可通过抽屉打开；所有入口均可键盘聚焦。
5. 图表保持异步加载、可见 SVG、卸载销毁与空状态，既有根路由与 404 验收仍通过。

## 非目标

- 不新增导航目的地、数据筛选、任务编辑、通知中心或用户菜单交互。
- 不更改 API、状态管理、实体层演示数据的结构。
- 不为视觉效果引入新的 UI、图表、动画或 CSS 框架依赖。

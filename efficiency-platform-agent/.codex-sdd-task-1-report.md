## 自审与风险

- 本地响应只接受规范化后的完整稳定短句或受控全匹配问候；例如“帮我策划一次新品品牌活动”不会被消耗，降低运营请求误路由风险。
- `general_chat` 仍复用既有冻结的 `IntentEnvelopeV1` JSON 结构；`requirements` 中只允许固定版本字段，不扩展开放字段。
- 本任务只完成本地响应和意图提示层。`ConversationService` 的 DIRECT 路由、普通聊天模型执行、SSE 端到端验收和真实模型行为属于后续 Task 2 至 Task 4，尚未在本任务验证。
- 未发现需同步的架构门禁修改；现有 AST 架构测试 12/12 通过。

# 智能客服父子切片 PostgreSQL 变更

> 状态：已在开发库执行并验证
>
> 负责人：项目开发与验收
>
> 适用范围：Agent 自有 PostgreSQL 开发库 `jjcy_ai_vector` 的 `customer_service` Schema；其他环境待执行
>
> 最后更新：2026-10-22
>
> 关联设计：`docs/superpowers/specs/2026-10-22-智能客服父子切片与证据组装-设计.md`

本变更新增父片段表和子片段关联字段；既有 `document_chunk` 数据保持不变，新字段允许为空以保留历史索引。开发库已按 `01-precheck.sql` 只读预检，在用户授权后执行 `02-up.sql` 并以 `03-verify.sql` 验证，再重新入库与发布新父子索引。其他环境仍须分别预检、授权、执行和验证。`04-down.sql` 会删除新父片段与关联字段，只能在确认没有依赖它们的已发布索引后，经单独授权执行。

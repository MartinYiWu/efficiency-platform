# S7 PostgreSQL 隔离命名空间变更

## 预检

执行 `01-precheck.sql` 前必须取得本次 `NETWORK_PROBE` 授权。预检只读检查 PostgreSQL 版本、当前身份、事务能力、`vector` 扩展是否已安装以及目标 Schema 是否不存在。

## 影响

变更仅作用于固定的 `s7_acceptance_00000000` Agent 验收 Schema，最多承载合成运行记录、事件、用量、Checkpoint 与 1024 维 Chunk。不得访问其他命名空间；本包不安装扩展。

## 验证

取得独立 `WRITE_ACCEPTANCE` 后执行 `02-up.sql`，再执行 `03-verify.sql` 核对表、租户条件、向量空间和原生 FTS。真实数据库 Gate 默认关闭，本地测试不建立连接。

## 回滚

无论验证成功或失败，按授权中的清理责任执行 `04-rollback.sql`，随后只读回读 Schema 不存在。禁止全库清理或修改非本包对象。

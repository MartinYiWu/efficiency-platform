# Prompt 资产多角色装配变更说明

## 授权与目标

本变更用于开发环境 Agent MySQL `ai_efficiency_platform_agent`，已获准保存可版本化的多角色 Prompt、模型策略、输出契约、发布映射和 Run 快照。

## 预检

执行 `01-precheck.sql`，确认当前数据库、MySQL 版本、既有 `agent_run` 表以及九张目标表是否已存在。发现同名表时停止，先核对历史迁移，禁止覆盖。

## 影响

新增九张 `agent_` 前缀表，不修改既有运行表和业务数据。Prompt 正文使用 `LONGTEXT`，Schema 和测试输入使用 MySQL `JSON`。

## 执行

执行 `02-up.sql`。外键只连接本变更表以及既有 `agent_run`，发布版本与定义的一致性由发布事务和验证 SQL 共同保证。

## 验证

执行 `03-verify.sql`，确认表、唯一键、外键引用、发布归属和快照引用均有效；任何非零异常计数都视为失败。

## 回滚

仅在确认没有运行依赖这些 Prompt 快照时执行 `04-rollback.sql`。脚本按依赖逆序删除本变更新增的九张表，不删除数据库、Schema 或既有 Agent 表。

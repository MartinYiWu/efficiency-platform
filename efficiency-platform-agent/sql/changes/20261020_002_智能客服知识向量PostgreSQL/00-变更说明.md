# 智能客服知识向量 PostgreSQL 变更

> 状态：执行中  
> 负责人：AI 效能平台研发  
> 适用范围：`vector.datasource` 指向的 PostgreSQL 开发库 `jjcy_ai_vector` 的 `customer_service` Schema  
> 最后更新：2026-10-20  
> 关联决策：AI 智能客服首个完整闭环详细设计

## 预检

`01-precheck.sql` 只读确认当前数据库、`vector` 扩展、目标 Schema 和表冲突。此变更不安装扩展，目标数据库必须已具备 pgvector。

## 影响

`02-up.sql` 新增 `customer_service.document_chunk` 与 `customer_service.index_release_document`，Embedding 固定为 `vector(1024)`，使用 cosine HNSW 和 PostgreSQL 原生全文 GIN 索引。

## 验证

`03-verify.sql` 只读核对 Schema、字段、1024 维向量类型、索引和固定模型约束。

## 回滚

`04-rollback.sql` 只删除 `customer_service` Schema。本 Schema 仅归智能客服知识向量使用，回滚前必须确认并备份需要保留的 Chunk。

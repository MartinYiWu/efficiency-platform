新增SCRUBBED状态、nullable snapshot_ciphertext/snapshot_nonce和精确body CHECK；保留原tenant/execution/runtime、请求/上下文指纹、原deadline、epochs及key版本。新增invalidation receipt技术阶段证明字段，不新增业务job。只有可信STOP和THREADS均持久确认的执行才允许清快照。SCRUBBED不能回到ACTIVE/REVOKED，epochs不能回退，执行锚点不可替换。技术运行JSON按受信清理入口清其memory_execution/输出与技术输入内容，保留身份/预算/用量/版本/指纹并显式拒恢复；不删除Java展示消息或业务档案。

回滚不可恢复已擦正文。04脚本只用于无SCRUBBED行且已停记忆流量时恢复旧结构；必须人工确认查询为0后执行，不伪造旧ciphertext。运行时只依赖新增列，缺delta明确存储不可用，不降级跳过擦除。

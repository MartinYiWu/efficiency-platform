# Memory Index v1（仅待审资产，默认关闭）

仅Agent自有PostgreSQL schema，复用已配置PostgresProvider连接；不创建共享库、扩展或额外账本。
索引只持久化有界向量、脱敏词项、item/version/generation/epoch/source指纹引用；不保存projection正文。
JSON向量按授权集合<=10000精确余弦排序，不创建ANN。所有结果还需Java当前权限hydrate。

先停索引Worker、备份目标schema并审阅角色权限，设置现有Agent独占schema为search_path后依次
人工执行precheck/up/verify；未获真实DDL授权不得执行。默认不自动迁移或启用。
rollback关闭投影可用标记并清空派生向量/词项，保留删除fence、INFLIGHT/UNKNOWN及task去重槽；
禁止DROP这些保护表或以旧备份回滚费用/删除代次。24h未决操作由pending_operations只读告警，
不会自动再Embedding。删除在同事务提交fence与投影清理，投递失败由原Outbox重放同delete补偿。

首版单条即一个有界索引批次：同task仅一次写索引机会；不自动循环多条或另建task绕配额。
若需多条批量，必须新增固定batch合同和一次供应商批请求，不能逐条重复调用。

自然到期由已装配backend的独立CPU worker每30秒处理全自有schema，单批最多100条entry和100条QUERY，
实际删除entry向量/词项，QUERY擦除embedding/item_refs，保留task slot/fingerprint/UNKNOWN/epoch墓碑。
QUERY.expires_at首次冻结为原授权截止与当前合法索引最短保留期的交集，超期不复用或重新Embedding。
独立cleanup开关可以在新写/召回关闭时运行worker；shutdown先取消并await worker再关PG连接。

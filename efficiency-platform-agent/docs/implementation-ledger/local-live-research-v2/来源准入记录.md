## 程序约束与后续验收

加载器仅接受已登记的五个稳定身份及其 adapter/access/publisher/host 组合；端点独立静态冻结。
未知 ID、fixture ID、未知域名、身份错配、未知字段和全文存储扩大均拒绝。Registry 构建与每次调用分别检查准入，
过期、未知费用、用途缺失和仅 enabled 的配置不能获得网络调用配额。
来源 host 白名单不等于允许任意路径；Task 4 必须按静态端点和已登记路径装配 Provider，不能反射返回 URL 注册新源。

Feed 的 `body_content_scope` 默认 summary；只有组合根具有已核验的完整正文语义及处理许可时才可显式设为 full，
description/summary 即使在 full 来源中仍是 summary。GitHub REST Release body 标为 platform_text 并附
`attributed_release_notes_only` 标签；它只说明这份发布说明表达了什么。arXiv/HN 已有正确范围，未改 Provider。

本批未接入正式网络链路、未重启服务、未执行两轮真实研究。Task 9 必须在当期授权内刷新端点/历史/内容证据；
仍没有合格正文或获准平台文本时保持关闭，真实正向验收记为未完成，不能以离线样本替代。

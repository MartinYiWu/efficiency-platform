## 实现与边界

会话在 queued 回调记录最近提交 Run 与用户，并为本轮绑定前驱；终态监听不回写该指针，避免晚到结果或历史回退。命中明确阿拉伯数字“第 N 条”及“改写/改成/写成”时，在意图模型前校验身份、成功终态、严格 V2 Schema、Run 标识、排名唯一性、交付/引用闭包和既有展示安全门。无平台时返回 `CONVERSATION_REFERENCE_PLATFORM_REQUIRED`；其他缺失或无效引用返回 `CONVERSATION_REFERENCE_UNAVAILABLE`。

类型化 `ReferencedRankedInput` 经过 ScenarioSubmission、ScenarioSupervisorRequest 传递，由 Supervisor 裁剪到一个 item 与其来源。保留原始 rank 与 citation_id；同 URL 不合并不同 V2 引用标识。来源只裁剪 supports_item_ids，不能携带其他条目。没有传入整段历史，也没有将 V1 正文转换成 V2。

校验助手放在 Harness，复用已有交付质量能力；Conversation 不新增对 capabilities 的反向依赖。继续使用现有 Supervisor、注册专家和模型预算边界。

> **执行约束：** 仅建设纯 Agent 侧骨架；不包含 Java 侧、具体业务 Agent、部署拓扑、ASR/TTS、内容审核和付费热点数据源。本次不提交 Git。

**目标：** 在空目录中建立一个技术框架中立、可测试、支持未来多 Agent 协作的 Python 工程骨架，并形成下一阶段技术组件选型基线。

**架构：** 采用 Harnessed Hybrid Multi-Agent Architecture。Agent Harness 统一包裹执行，Strategy Router 在 Direct、Workflow、ReAct、Plan-and-Execute、Supervisor Multi-Agent 之间选择；所有策略共用 Graph Runtime、Context、Tool Runtime、Memory、Persistence、Observability、Security 和 Evaluation 边界。

**当前技术约束：** 骨架实现只使用 Python 标准库，不引入具体 Agent 框架、Web 框架或模型 SDK。第三方组件只在选型文档中裁决，不在本阶段安装。

1. 编写结构契约测试，要求所有一级架构包、五类策略包和关键能力包存在。
2. 编写核心契约测试，要求存在统一的运行状态、策略模式和扩展端口。

# P0 Python 与 uv 环境升级实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留系统 CPython 3.11.9 的同时，安装 uv、安装 uv 托管的 CPython 3.13、把 Agent 项目固定到 3.13，并用新解释器完成既有骨架测试。

**Architecture:** uv 作为用户级环境工具安装，不覆盖系统 Python。项目通过 `.python-version` 与 `pyproject.toml` 声明 CPython 3.13，通过项目 `.venv` 隔离解释器；本次不安装 FastAPI、LangGraph 等 P0/P1 运行依赖。

**Tech Stack:** Windows PowerShell、uv、CPython 3.13、`pyproject.toml`、标准库 `unittest`

## Global Constraints

- 保留 `C:\Program Files\Python311\python.exe`，不得卸载、覆盖或修改该系统解释器。
- 使用 uv 官方 Windows standalone installer；当前机器无 WinGet，不使用来源不明的安装包。
- uv 只安装受管理的版本化 CPython 3.13，不使用实验性 `--default` 覆盖全局 `python.exe`。
- 项目 Python 约束固定为 `>=3.13,<3.14`，默认解释器请求固定为 `3.13`。
- 本次不得引入 FastAPI、Uvicorn、Pydantic、HTTPX、LangGraph、Celery 或其他业务运行依赖。
- 不执行数据库、部署、Java、Git 或外部服务操作。
- 环境变更后必须分别验证系统 Python 仍为 3.11.9、项目 Python 为 3.13.x，并在项目 Python 下执行完整测试。

### Task 1: 安装并验证 uv

**Files:**
- External user tool: `%USERPROFILE%\.local\bin\uv.exe`

**Interfaces:**
- Consumes: uv 官方 HTTPS standalone installer
- Produces: 当前用户可执行的 `uv` 与 `uvx`

- [x] **Step 1: 记录安装前状态**

运行：

```powershell
python --version
py --list-paths
Get-Command uv -ErrorAction SilentlyContinue
```

预期：系统 Python 为 3.11.9，Launcher 仅列出 3.11，uv 不存在。

- [x] **Step 2: 使用官方安装器安装 uv**

运行：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

预期：安装器成功，并显示 uv 安装目录；不得改写系统 Python。

- [x] **Step 3: 解析当前会话中的 uv 路径并验证**

运行：

```powershell
$uvExe = Join-Path $env:USERPROFILE '.local\bin\uv.exe'
& $uvExe --version
```

预期：退出码 0 并输出已安装 uv 版本。

### Task 2: 安装并固定 CPython 3.13

**Files:**
- Create: `.python-version`
- Modify: `pyproject.toml`
- Create: `.venv/`（uv 管理的项目环境）
- Create: `uv.lock`

**Interfaces:**
- Consumes: Task 1 的 uv 可执行文件、现有标准库项目骨架
- Produces: `requires-python = ">=3.13,<3.14"`、默认 Python 请求 `3.13`、隔离项目解释器

- [x] **Step 1: 安装 uv 托管的 Python 3.13**

运行：

```powershell
& $uvExe python install 3.13
& $uvExe python list --only-installed
```

预期：列表同时可以发现系统 3.11 和 uv 托管的 CPython 3.13；不创建全局默认 `python.exe`。

- [x] **Step 2: 固定项目默认解释器**

运行：

```powershell
& $uvExe python pin 3.13
```

预期：项目根目录创建 `.python-version`，内容为 `3.13`。

- [x] **Step 3: 写入项目 Python 约束**

将 `pyproject.toml` 的 `[project]` 更新为：

```toml
[project]
name = "efficiency-platform-agent"
version = "0.1.0"
description = "Framework-neutral foundation for the efficiency platform Agent runtime."
requires-python = ">=3.13,<3.14"
dependencies = []
```

- [x] **Step 4: 创建锁文件和项目环境**

运行：

```powershell
& $uvExe lock
& $uvExe sync
```

预期：创建 `uv.lock` 与 `.venv`；因为运行依赖仍为空，不安装 P0/P1 组件。

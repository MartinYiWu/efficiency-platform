# 运营 Agent 受控混合执行升级实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. 本项目永久不是 Git 仓库，使用文件快照、测试输出和进度账本替代提交与 Git 审查。

**Goal:** 将运营 Agent 升级为确定性研究快速通道、Supervisor 研究前置、多平台独立生成、分阶段预算和真实 8 类验收的受控混合执行链。

**Architecture:** 普通聊天继续走 Direct；明确联网请求由快速意图预判直接进入运营 Multi-Agent；复杂请求仍由 LLM IntentInterpreter 解析。Supervisor 在需要研究时先调用真实 ResearchProvider 建立 EvidencePack，再并行调度平台 Specialist；每个阶段都通过结构化契约、预算和 SSE 事件治理。

**Tech Stack:** Python 3.13、uv、FastAPI、Pydantic v2、DeepSeek Responses API `web_search_2025_08_26`、现有 LangGraph/自研 Supervisor、pytest、Ruff、mypy。

## Global Constraints

- 纯 Agent 侧范围；不修改 Java 侧、部署拓扑或业务数据库。
- 保持 LangGraph 为唯一 Graph Runtime，不引入 LangChain、第二套 Agent 框架、爬虫或付费商业热点数据源。
- DeepSeek Web Search 只能通过现有 Provider Port 调用；不得访问模型返回 URL，不得用普通模型回答伪装联网结果。
- 研究失败必须失败关闭；不得生成声称已经完成最新联网核验的无来源正文。
- 任何内部 Prompt、模型原始响应、工具细节和隐藏推理不得进入用户 SSE 或最终交付。
- 代码、测试、Prompt、Docstring、日志字段说明使用中文；技术标识符保留英文。
- 所有生产代码变更必须先有失败测试；真实外部验收与离线回归必须分开记录。
- 项目不使用 Git；不得执行或声称 Git 初始化、提交、分支、推送或 Git diff。

### Task 3: Supervisor 研究前置与分阶段执行

**Files:**

**接口与行为：**

- `OperationAgent` 显式持有 `ResearchProviderPort | None`，但不直接实例化厂商 SDK。
- `ScenarioSupervisorAdapter` 在 `request.task_spec.requires_research` 为 True 时调用注入的 ResearchProvider，校验 `ResearchResult`，通过 EvidenceGate 后将 `EvidencePack` 注入本次 Supervisor 请求；失败立即返回 `RESEARCH_UNAVAILABLE` 或稳定证据错误。
- 多平台节点只读取当前 Supervisor 的 EvidencePack，`_ScenarioDispatch` 将证据引用和研究阶段结果传给每个平台 Specialist；无研究请求时 `research=False`，不调用研究 Provider。
- 研究预算独立于平台预算：研究默认 `timeout_ms=150_000`、`max_output_tokens=8_000`；平台生成沿用每节点预算，但总 Run 预算扩大到可容纳“研究 + 生成”两个阶段，具体上限由配置常量集中声明。

- [ ] 写失败测试：`requires_research=True` 的多平台提交调用一次 Fake ResearchProvider，三个平台 Specialist 均收到相同有效 EvidencePack，最终有三个独立成品。
- [ ] 写失败测试：研究 Provider 失败时三个平台均不生成无来源成品，结果为 `RESEARCH_UNAVAILABLE`。
- [ ] 写失败测试：`requires_research=False` 时 ResearchProvider 调用次数为 0，既有多平台离线场景不退化。
- [ ] 运行目标测试并确认红灯。
- [ ] 实现 Supervisor 前置研究、EvidencePack 注入和分阶段预算；保持研究 Provider 只返回契约，不泄露厂商异常正文。
- [ ] 运行目标测试、既有全量非真实测试和 `uv run mypy src`，确认绿灯或记录现存非相关警告。

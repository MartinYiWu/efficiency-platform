# 运营 Agent 对话接入与全链路联调实施计划

> **执行约束：** 使用 `subagent-driven-development`（推荐）或 `executing-plans`。每个任务使用复选框跟踪，并在任务完成后执行对应验证。

**目标：** 将运营助手前端的自然语言对话接入 Agent 运行主链，支持真实 DeepSeek、受控多 Agent 编排、SSE 流式输出、多平台交付物和浏览器真实验收。

**架构：** 使用 Conversation Facade 接收自然语言并复用现有 Run 生命周期；使用 IntentInterpreter 和 ScenarioResolver 将开放输入转换为受控 `ScenarioSubmission`；使用 GraphRuntime、Supervisor、Specialist 和 DeliverableAssembler 执行并通过实时 Event Hub/SSE 返回前端。开发阶段采用 InMemory 适配器，Fake 仅用于显式自动化测试，人工联调默认使用真实 DeepSeek。

**技术栈：** Python 3.13、uv、FastAPI、Pydantic、现有 GraphRuntime/Supervisor/Specialist、DeepSeek OpenAI-compatible API、SSE、React 19、Vite、TypeScript、浏览器 Network/Playwright 验收。

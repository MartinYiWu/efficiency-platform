# Agent 关键执行与错误日志 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Agent 本地运行补齐可关联、可定位、默认脱敏的关键执行与错误日志，并让当前 `RESEARCH_UNAVAILABLE` 能显示真实失败阶段。

**Architecture:** 在 Core 定义不可变诊断契约和 ContextVar Run 上下文，通过窄 `DiagnosticRecorderPort` 注入现有本地日志器。Harness、Graph、ModelRuntime 与 Research Provider 只产生白名单诊断事实，用户可见错误契约保持不变。

**Tech Stack:** Python 3.13、stdlib logging、contextvars、dataclasses、pytest；不新增运行依赖。

## Global Constraints

- 项目永久不是 Git 仓库，不执行或声称 Git 初始化、提交、分支、推送或 Git diff。
- 所有新增注释和 Docstring 使用中文；标识符、稳定错误码与标准技术术语可保留英文。
- 不读取、打印、修改或校验 `.env` 中的配置值。
- 不记录用户正文、历史、Prompt、模型正文、来源全文、Key、Authorization、Cookie、连接串、请求体或响应体。
- 不记录逐 Token 或逐 SSE delta 日志。
- 不引入 structlog、OpenTelemetry、Collector、Prometheus、Grafana、LangSmith 或监控平台。
- 用户可见 API/SSE 错误只保留既有安全错误契约。
- 新增行为必须先有有效 RED，再做最小 GREEN。

## Global Constraints

- 继承总计划全部约束：唯一 LangGraph、可信身份/权限、统一模型和预算、外部内容不可信、无共享 DDL。
- 业务新闻、写作、时间和多轮表达不得通过关键词快路径直接放行；协议按钮操作和幂等重放可保留确定性快路径。
- 不伪造 confidence；READY 依赖结构、来源、时间、注册、权限、必填字段、无环依赖全部满足。
- 解释最多 3 次模型调用，其中格式修复最多 1 次、语义复核最多 1 次；重试和供应商降级的实际尝试也受父预算约束。
- 澄清每次仅问一个阻断问题，最多 2 轮；技术失败不是用户表达不清，不用澄清掩盖 Provider 故障。
- 时区优先用户明确值、会话、租户、Asia/Shanghai 默认；窗口左闭右开，时间 anchor 冻结，不随恢复漂移。
- GoalNode 最多 8 个；模型只能引用注册能力，不得动态 import、创建工具或设置身份和预算。
- I01—I07 已完成离线实现与回归，状态和证据逐项写入总计划指定账本；真实模型评测仍归 X04，未执行不得标记通过。

```python
from datetime import datetime, time, timedelta, timezone as dt_timezone
from zoneinfo import ZoneInfo

def previous_local_day(anchor: datetime, zone_name: str) -> tuple[datetime, datetime]:
    if anchor.tzinfo is None:
        raise ValueError("基准时间必须包含时区")
    zone = ZoneInfo(zone_name)
    today = anchor.astimezone(zone).date()
    start = datetime.combine(today - timedelta(days=1), time.min, zone)
    end = datetime.combine(today, time.min, zone)
    return start.astimezone(dt_timezone.utc), end.astimezone(dt_timezone.utc)
```

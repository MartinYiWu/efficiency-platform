# Agent 免费多源研究闭环实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 用户选择委派时才使用 superpowers:subagent-driven-development。步骤使用复选框，实际执行证据记录到总计划的阶段账本。

**Goal:** 通过免费可用 API、RSS 和公开信息完成采集、过滤、事件整合、证据评估、有界补采与标准交付；不再把任意失败压成“请稍后重试”。

**Architecture:** ResearchBriefV2 驱动现有 LangGraph 内的研究子图，所有网络操作经 Tool Runtime/Provider。确定性代码裁决来源准入、预算、引用位置和交付门槛；LLM 提出语义筛选、聚类、事实与补采候选，不能自封成功。

**Tech Stack:** Python 3.13、Pydantic v2、LangGraph 1.x、HTTPX、准入后的 feedparser/Trafilatura、现有 ModelRuntime/Artifact/PostgreSQL；不部署浏览器、搜索集群或第二框架。

## Global Constraints

- 完整继承总计划边界与 C02 中立契约；R01—R10 已完成离线实现与回归，真实来源准入及公网验收仍归 X04，所有来源继续保持禁用。
- 只允许 VERIFIED 且 free/可零收费硬停止 free_quota 的来源；unknown/paid/过期试用保持禁用。
- 公开可访问不等于允许任意抓取/全文分发；记录站点条款、robots、访问、保存、引用限制，不绕过认证、付费墙和反爬。
- 不依赖现有厂商 web_search，不把免费试用、付费账户附送接口或收费未知接口归为免费。
- 原始时间未知不填当前时刻；RSS 最新列表不证明历史完整；完整计划内无匹配不等于全网没有。
- 首轮最多初采1+补采2，输出修复1；总截止、请求数、Token、费用由父账本统一约束。
- 来源网页不改变意图/权限/预算；Provider 不实例化模型；正文不进 Graph State、日志和 SSE。
- 仅支持允许的 API/Feed/静态 HTML；不下载 PDF 全文/图片/视频，不启动浏览器兜底。

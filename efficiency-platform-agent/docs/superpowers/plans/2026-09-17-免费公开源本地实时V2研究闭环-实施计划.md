> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 按项目永久非 Git 规则，技能中的提交、分支与 worktree 步骤替换为文件快照、文件级差异包和项目进度账本。每任务独立复核后再进入下一任务。

**Goal:** 让本地正式会话通过已准入免费公开源完成真实 V2 研究、可核验排名交付和上一轮第 N 条改写，同时保持租户、预算、来源正文与生产门禁。

## 交付、失败关闭及计划自审

交付结论分开列“源码已实现”“离线门禁结果”“真实来源准入”“真实两轮正向结果”“生产未验收”。只有前三项通过且真实正向两轮证据完整，才能称本地实时 V2 闭环完成。production 无论如何保持单独待持久化/恢复/部署验收，不因本计划完成自动开放。

失败矩阵：无权限/未知费用/源或 host 不在白名单 → 网络前拒绝；只有摘要/缺许可 → 禁止升级全文，补采或 PARTIAL/FAILED；部分来源失败 → 记录 attempt 和覆盖缺口；全失败 → FAILED；来源成功但历史不完整 → 不能 NO_MATCHES；用户取消/硬截止 → CANCELLED/TIMED_OUT，迟到结果不发成功交付；输出引用失败 → 最多一次修复或确定性降级，仍失败则关闭。

自审映射：显式模式 Task 1/8；真实 descriptor/registry Task 2；内存/身份/预算 Task 3；Tool Runtime/正文 Task 4；正式 StageRunner Task 5；materializer/交付 Task 6；跨轮与普通聊天 Task 7；端口/服务/回滚 Task 8；独立复核和真实证据 Task 9。文件路径、接口签名与测试命令在各任务内给出。不存在生产门放宽、test_mode 启用真实服务、假 postgres、V1 文本伪 V2 或测试样本冒充真实验收步骤。

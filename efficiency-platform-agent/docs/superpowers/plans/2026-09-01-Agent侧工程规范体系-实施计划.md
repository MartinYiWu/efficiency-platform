> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `efficiency-platform-agent` 建立对人类开发者与编码 Agent 同时生效、可导航、可检查的强工程规范体系。

**Architecture:** 根目录 `AGENTS.md` 承载最高优先级强制规则，`Agent.md` 承载 Agent 架构和扩展总纲；详细规则拆入 `docs/standards/`，复用结构放入 `docs/templates/`，SQL 就近规则放在 `sql/README.md`。新增标准库结构测试，防止必要文档、核心章节和关键边界被误删。

**Tech Stack:** Markdown、Python 3.11+ 标准库 `unittest`、现有 AST 架构守卫。

## Global Constraints

- 只定义纯 Agent 侧规则，禁止扩展到 Java 侧架构或部署拓扑。
- 规则使用 MUST / MUST NOT / SHOULD / MAY 分级，并提供中文含义。
- 标识符使用英文；文档使用中文；注释允许中文并保留标准技术术语。
- 文档不得包含无解释的占位项、伪造验证结果或尚未安装工具的通过声明。
- 共享数据库 DDL 必须经过只读预检、影响说明和用户明确授权，本计划不创建或执行实际 DDL。
- 不新增具体业务 Agent、ASR、TTS、内容审核和付费热点数据源实现。
- 当前目录不是 Git 仓库，不执行 `git add`、`git commit`、分支、合并或 PR 操作。
- 所有文件通过 `apply_patch` 创建或修改，保护现有架构文档和测试。

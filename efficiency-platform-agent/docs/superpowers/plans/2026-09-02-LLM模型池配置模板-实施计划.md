# LLM 模型池配置模板 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 整理旧 Java 可复用的 PostgreSQL、Redis、DashScope 与 COS 本机配置，交付 DeepSeek 默认 LLM 配置模板、未来模型池预留和可自动验证的配置契约，不实现模型调用、路由算法或外部连接。

**Architecture:** 使用版本控制的 `config/llm-routing.toml` 保存非敏感路由语义、逻辑能力层级与 Provider 注册信息；使用被 `.gitignore` 排除的本地 `.env` 保存端点、API Key 与实际模型 ID，并只提交空值 `.env.example`。经项目负责人本次明确授权，可从旧 Java 开发配置迁移 PostgreSQL Vector、Redis 和已有 COS/DashScope 值到本机 `.env`；DeepSeek 的地址、Key 与模型 ID 保持空值，由项目负责人后续自行填写。当前只启用 `deepseek_direct`；未来 `model_pool` 保持禁用且不假定其协议，真正的 `ModelPolicyRouter` 和 Provider Adapter 仍属于后续 P1/P2 实施。

**Tech Stack:** CPython 3.13 标准库 `tomllib`、`unittest`、TOML、dotenv 兼容键命名；不新增第三方依赖。

## Global Constraints

- 实现必须符合[ADR-0001 自适应模型策略路由](../../adr/ADR-0001-自适应模型策略路由.md)：Agent 只能提出能力需求，Harness 才能作最终模型选择。
- 当前默认 LLM Provider 是 `deepseek_direct`；旧 Java AIHub 配置、账号、密码和 Key 不迁移。
- 不得向仓库写入真实 API Key、端点、密码、连接串或模型采购信息；`.env` 与 `.env.*` 必须忽略，只有 `.env.example` 可以提交。本次用户明确授权的旧 Java 凭据只允许进入项目根本机 `.env`，不得进入补丁、文档、测试、日志或终端输出。
- 模型能力使用 `fast`、`balanced`、`strong` 逻辑层级；不得在业务 Agent、Prompt、Graph 或测试中写死厂商模型 ID。
- 强模型故障时允许降级到快模型，但预算、时限、最大尝试数、能力兼容和可恢复失败仍由后续 Harness 实现；本计划不实现这些运行时行为。
- 不安装 OpenAI SDK、pydantic-settings、LiteLLM 或任何模型 SDK；不调用 DeepSeek，不运行网络 PoC。DeepSeek 地址、API Key 和模型 ID必须在本次整理中保持空值。
- 运行命令使用 `& '.\\.venv\\Scripts\\python.exe'`；当前目录不是 Git 仓库，Git checkpoint 必须跳过并在交付中如实说明。

## File Structure

- Create: `.env.example` — 用户本机填写前的空值环境变量模板；不含真实值。
- Create: `.env` — 本机忽略的配置文件；只接收本次获授权从旧 Java 开发配置迁移的 PostgreSQL Vector、Redis、DashScope 与 COS 值，DeepSeek 和未来模型池值为空。

- Create: `tests/config/test_llm_configuration_template.py` — 用 `tomllib` 和标准库验证模板语义、Key 为空与忽略规则。

```python
from __future__ import annotations

import tomllib
import unittest
from pathlib import Path


PROJECT_ROOT = Path(__file__).resolve().parents[2]


class LlmConfigurationTemplateTest(unittest.TestCase):
    def test_routing_template_declares_dynamic_deepseek_default(self) -> None:
        content = (PROJECT_ROOT / "config/llm-routing.toml").read_bytes()
        document = tomllib.loads(content.decode("utf-8"))

        self.assertEqual(
            document["router"]["selection_mode"],
            "agent_proposed_with_harness_guardrails",
        )
        self.assertTrue(document["router"]["allow_lower_tier_degrade_on_retry"])
        self.assertEqual(document["providers"]["deepseek_direct"]["enabled"], True)
        self.assertEqual(
            document["providers"]["deepseek_direct"]["api_key_env"],
            "AGENT_LLM_DEEPSEEK_API_KEY",
        )
        self.assertEqual(
            document["routes"]["chat_default"]["selection_order"],
            "adaptive",
        )
        self.assertEqual(
            document["routes"]["chat_default"]["allowed_tiers"],
            ["fast", "balanced", "strong"],
        )

    def test_future_model_pool_is_reserved_but_disabled(self) -> None:
        document = tomllib.loads(
            (PROJECT_ROOT / "config/llm-routing.toml").read_text(encoding="utf-8")
        )

        pool = document["providers"]["model_pool"]
        self.assertFalse(pool["enabled"])
        self.assertEqual(pool["adapter_kind"], "unconfigured")
        self.assertEqual(pool["api_key_env"], "AGENT_LLM_MODEL_POOL_API_KEY")

    def test_env_template_contains_empty_secret_values_only(self) -> None:
        lines = (PROJECT_ROOT / ".env.example").read_text(encoding="utf-8").splitlines()
        values = {
            key: value
            for line in lines
            if line and not line.startswith("#") and "=" in line
            for key, value in [line.split("=", maxsplit=1)]
        }

        for key in (
            "AGENT_LLM_DEEPSEEK_BASE_URL",
            "AGENT_LLM_DEEPSEEK_API_KEY",
            "AGENT_LLM_DEEPSEEK_FAST_MODEL",
            "AGENT_LLM_DEEPSEEK_BALANCED_MODEL",
            "AGENT_LLM_DEEPSEEK_STRONG_MODEL",
            "AGENT_LLM_MODEL_POOL_BASE_URL",
            "AGENT_LLM_MODEL_POOL_API_KEY",
        ):
            self.assertIn(key, values)
            self.assertEqual(values[key], "")

    def test_gitignore_keeps_local_env_out_of_version_control(self) -> None:
        content = (PROJECT_ROOT / ".gitignore").read_text(encoding="utf-8")

        self.assertIn(".env", content)
        self.assertIn(".env.*", content)
        self.assertIn("!.env.example", content)
```

- [x] **Step 1: 创建版本控制的路由模板**

创建 `config/llm-routing.toml`，内容如下：

```toml
[router]
selection_mode = "agent_proposed_with_harness_guardrails"
default_route = "chat_default"
allow_lower_tier_degrade_on_retry = true

[providers.deepseek_direct]
enabled = true
adapter_kind = "openai_compatible"
base_url_env = "AGENT_LLM_DEEPSEEK_BASE_URL"
api_key_env = "AGENT_LLM_DEEPSEEK_API_KEY"

[providers.model_pool]
enabled = false
adapter_kind = "unconfigured"
base_url_env = "AGENT_LLM_MODEL_POOL_BASE_URL"
api_key_env = "AGENT_LLM_MODEL_POOL_API_KEY"

[routes.chat_default]
selection_order = "adaptive"
allowed_tiers = ["fast", "balanced", "strong"]

[[routes.chat_default.candidates]]
provider = "deepseek_direct"
tier = "fast"
model_env = "AGENT_LLM_DEEPSEEK_FAST_MODEL"

[[routes.chat_default.candidates]]
provider = "deepseek_direct"
tier = "balanced"
model_env = "AGENT_LLM_DEEPSEEK_BALANCED_MODEL"

[[routes.chat_default.candidates]]
provider = "deepseek_direct"
tier = "strong"
model_env = "AGENT_LLM_DEEPSEEK_STRONG_MODEL"
```

`selection_order = "adaptive"` 表示候选声明不是固定调用顺序；未来 Harness 根据 Agent 需求、模型能力、健康度、预算和时限选择。`model_pool` 在其真实协议和模型能力未确认前必须保持禁用。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Every behavior change follows test-first RED → GREEN → REFACTOR. This workspace is permanently non-Git, so use file snapshots, task reports and the progress ledger instead of commits.

**Goal:** 将运营助手升级为不暴露底座、可按需联网研究、真正 SSE 增量输出并具备简洁思考动效和打字机体验的对话式 Agent。

**Architecture:** DIRECT 普通聊天使用统一模型运行时的真实流式入口；研究和运营多 Agent 继续在质量门后输出最终正文。前端只展示统一思考动效，不展示推理过程，通过权威正文与可见正文分离实现打字机。

**Tech Stack:** Python 3.13、FastAPI、LangGraph、Pydantic、OpenAI-compatible SDK、pytest、React 19、TypeScript、Vitest、Ant Design、SSE。

## 全局约束

- 两个项目永久不是 Git 仓库，不执行或声称任何 Git 操作；
- 不读取、输出或校验 `.env` 中的真实密钥值；
- 项目代码注释、Docstring、配置注释必须使用中文；
- 不显示隐藏推理链、系统 Prompt、模型池、工具参数、内部节点或配置；
- 前端只显示三点思考动效，不显示阶段文字；
- 不新增第二 Graph Runtime，不绕过 Harness、Provider、Tool Runtime 或质量门；
- 不引入 ASR、TTS、视频、Text2SQL、内容审核、主动发布或付费商业数据源；
- 不启动常驻 Agent/前端实例，直到进入明确的本地联调任务；
- 每个任务必须先保存 RED 证据，再实施最小修复并保存 GREEN 证据；
- 完成声明必须附本轮新鲜测试、静态检查、构建和必要联调证据。

- 真实联调结论不超出实际证据；
- 所有本轮启动的临时服务在验收结束后已停止。

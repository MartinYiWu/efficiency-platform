# 运营 Agent 受控混合升级真实验收报告

## 1. 验收结论

本轮已按真实 HTTP/SSE 方式执行 R01～R08，运行模式为 `real`，配置门禁为 `READY`，未启用 Fake Provider、MockTransport 或无来源普通回答兜底。

本轮结论为 `DEVELOPMENT_INTEGRATION_READY_WITH_EXTERNAL_RESEARCH_LIMIT`：对话路由、三平台独立交付、上下文追问、澄清、阶段事件和安全错误已具备联调条件；真实研究型用例在 DeepSeek Web Search 未返回有效证据时会按设计失败关闭，因此不能宣称研究型全链路已通过。

## 2. 真实矩阵结果

| 用例 | 结果 | 说明 |
|---|---|---|
| R01 普通对话 | PASS | Direct 路由，未误触发研究 |
| R02 无联网三平台文案 | PASS | 公众号、小红书、头条各 1 份独立成品；SSE 阶段事件完整 |
| R03 下周 AI 热点三平台版本 | FAIL-CLOSED | 真实研究阶段未获得有效来源，返回 `RESEARCH_UNAVAILABLE`；未生成无来源内容 |
| R04 最近 7 天 AI 周报 | FAIL-CLOSED | 真实研究阶段未获得有效来源，返回 `RESEARCH_UNAVAILABLE`；未伪造引用 |
| R05 品牌/IP/活动策划 | PASS | 缺少关键业务条件时进入 `waiting_input`，要求用户补充信息 |
| R06 内容日历/选题规划 | PASS | 缺少关键范围时进入 `waiting_input` |
| R07 多轮追问与改写 | PASS | 上下文继承，定向复测产出 3 份平台成品并保留原约束 |
| R08 研究源不足/超时 | PASS（预期失败） | 观察到唯一失败终态和用户级错误；不回退为普通回答 |

R03 的真实输入为：`收集下周 AI 行业热点，整理成公众号、小红书和头条三种版本。`。本轮证据表明意图识别、研究阶段事件和安全失败路径均正确；缺少的是外部研究服务在该次请求中的有效来源，不是路由误判。

## 3. 关键行为核验

- 研究前置只执行一次，平台专家复用同一 EvidencePack，不重复联网。
- 平台专家并行执行，结果按平台形成独立 deliverable，不把三平台内容混成一份。
- SSE 输出包含 `intent_detected`、`phase_started`、`research_started`、`content_generation_started`、`content_generation_completed`、`quality_checked`、`assistant_delta`、`deliverable`、`stream_done` 等安全事件；内部 Prompt、工具参数和隐藏推理不进入事件载荷。
- 研究失败只暴露稳定错误码，不暴露供应商异常正文、密钥、内部堆栈或模型思考过程。
- 上下文追问“上一版/原有约束”能够读取可见对话历史并复用既有平台和主题，不要求用户重复输入。

# 运营 Agent 对话接入与全链路联调验收报告

## 1. 验收结论

本次交付已达到开发环境前后端联调体验标准：运营助手页面可通过 FastAPI 提交自然语言请求，Agent 在后台完成意图识别、受控场景选择、多 Agent 执行，并通过 SSE 返回澄清、增量状态、独立交付物、错误和终态。

结论限定为 `IMPLEMENTATION_READY / DEVELOPMENT_INTEGRATION_READY`，不是 `PRODUCTION_READY`。主要原因是当前真实模型池只有一个 DeepSeek 供应来源，真实调用存在偶发超时和结构化输出波动；真实公开联网搜索门禁仍关闭。

## 2. 验收范围

- 会话提交、幂等和租户隔离。
- 结构化意图、八类运营场景解析和澄清续轮。
- Run queued、running、waiting_input、succeeded、failed、cancelled 生命周期。
- SSE 回放、实时订阅、重连游标、去重、错误和终止事件。
- Supervisor、Specialist、质量门、部分成功和多平台独立交付物。
- FastAPI CORS 与 React 运营助手页面接入。
- 真实 DeepSeek 小规模调用和脱敏用量摘要。

## 4. 真实联调观察

### 4.1 成功路径

- 三平台内容由后端集成测试和确定性浏览器矩阵共同验证，生成小红书、微信公众号和今日头条三份独立成品；真实 DeepSeek 本轮只执行单平台代表性样本。
- 页面正确显示运行中、停止生成、澄清卡片、交付物卡片、平台、质量警告和终态。
- 真实浏览器已直连 `127.0.0.1:8080`，完成 CORS 预检、会话 POST、Run SSE GET 和单平台成品渲染；控制台错误和警告计数为 0。
- 确定性浏览器矩阵覆盖普通内容、三平台内容、活动策划、行业热点引用、信息不足、Specialist 部分失败、取消和 SSE 重连。
- 独立 Fake Agent Playwright 同时启动真实 FastAPI 和前端，不使用 `page.route`，并保存脱敏网络摘要、trace 与页面截图。
- 真实响应返回输入与输出 Token 用量；成本字段因当前模型价格表未配置而保持估算语义。

### 4.2 联调中发现并修复

- 等待输入或运行中的取消可能被晚到图结果覆盖：已改为状态锁内线性化仲裁，并增加取消竞态测试。
- 单平台请求曾执行全部平台步骤：已按确认的平台范围裁剪公开请求和执行计划。
- 澄清续轮曾可能丢失既有平台约束：已保存 Resolver 推导的实际缺失字段，只补齐缺失项。
- 未知平台曾可能回退到全部平台：已改为白名单和别名规范化后 fail-closed。
- 提交尚未返回时停止生成、随后取消接口失败的错误曾可能被忽略：已先绑定 Run 再处理待取消请求，并增加竞态回归测试。

### 4.3 外部模型波动

- 观察到真实 DeepSeek 偶发超过意图阶段截止时间。
- 观察到一次 Specialist 结构化结果未通过严格契约校验。
- 这些情况均被安全归一化为前端错误，不泄露异常栈或配置；由于尚无第二供应商候选，不能自动证明生产级可用性。

## 6. 风险与下一步准入条件

1. 接入至少一个可用的第二模型候选，验证强模型失败后自主降级到快模型。
2. 决定是否开启真实公开搜索门禁，并明确模型搜索能力的费用和配额边界。
3. 在业务功能稳定后再接入持久化运行事实、指标和监控，不提前建设监控平台。
4. 生产准入前补充真实并发、长连接稳定性、模型输出修复率和成本上限测试。

## 7. 流式输出边界

- 浏览器与 Agent 之间是完整 SSE 长连接，支持增量事件、断线续传和终态一致性。
- DeepSeek Streaming Provider 与 ModelRuntime 的流式、取消、错误和模型降级契约已有专项验证。
- 当前多 Agent 内容主链在质量门完成后，将已治理正文分块为 `assistant_delta`；不会把 Specialist 未校验的原始模型 Token 直接暴露给前端。
- 如果后续要求“生成过程中实时显示原始 Token”，应新增受控草稿事件和内容撤回语义，不能绕过质量门直接复用最终交付物事件。

## 1. 当前结论

本次实现已经通过 Agent 全量离线门禁、前端专项门禁、真实 DeepSeek 普通对话 API 验收和浏览器交互验收。结论边界为 `DEVELOPMENT_INTEGRATION_READY`，不等同于生产就绪。

真实公开研究本轮没有成功取得来源：现有研究 Gate/服务能力返回 `RESEARCH_UNAVAILABLE`。系统已验证会进入 `MULTI_AGENT` 研究路径、失败关闭、没有正文或引用，并向用户返回“本次未能完成在线核验，请稍后重试”。因此本报告不把联网研究标记为成功，只确认路由与失败透明性符合设计。

## 3. 真实联调观察

### 3.1 普通对话

- 身份问答使用本地稳定响应，`direct/succeeded`，零模型 Token；SSE 正文与保存正文一致。
- 普通知识问答默认使用真实 DeepSeek，`direct/succeeded`、`degraded=false`。
- 普通问答共收到 41 个 `assistant_delta`；首个正文在约 7040ms 到达，`stream_done` 在约 7200ms 到达，证明当前链路不是模型完成后的伪切片。
- 前端页面先显示无文字三点动效，首片后立即改为助手回答；截图时先观察到部分正文，3 秒后观察到完整两段正文。

### 3.2 研究请求

- 明确“搜索、核实、最近 7 天、来源”的请求进入 `MULTI_AGENT`，未落入无工具 DIRECT。
- 当前真实研究能力不可用，Run 以 `RESEARCH_UNAVAILABLE` 失败；SSE 顺序为意图、用量、运行、阶段、安全错误和唯一终止事件。
- 失败结果不包含助手正文、交付物或引用，没有调用普通模型生成伪研究成品。
- 该结果只证明失败关闭可用，不证明全网检索已经可用。

## 4. 联调中发现并修复

1. 研究 Gate 关闭时曾回退普通模型专家并允许无引用研究成功：已改为研究专家始终经过研究端口，缺失端口使用内存失败替身。
2. 意图模型误分时显式搜索请求可能进入 DIRECT：已增加会话服务确定性兜底；泛指追问继承可见用户历史，带主题请求优先当前消息。
3. 研究失败错误码虽正确但用户文案是“运行输出结构无效”：已映射为单次任务语义的“本次未能完成在线核验，请稍后重试”。
4. 取消、失败或澄清后的消息在下一轮可能恢复打字：已将冻结状态写入消息自身，并拒绝同 Run 迟到事件。
5. 前端全量回归发现两个既有测试的可访问名称/超时漂移：已同步当前复选框名称，并为两个重型页面用例设置明确超时；定向复验均通过。
6. 独立审查发现新请求提交到新 Run 绑定之间可能接收旧 Run 迟到事件：已先增加失败回归，再在该窗口拒绝所有 SSE；专项与全量前端测试均通过，复核确认问题关闭。

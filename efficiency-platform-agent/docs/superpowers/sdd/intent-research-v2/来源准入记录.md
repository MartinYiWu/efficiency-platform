## 当前决策

| 来源 | 成本 | 实际结果 | 决策与保存边界 |
|---|---|---|---|
| Google Blog RSS | free | HTTP 200，RSS Schema 合格 | VERIFIED/启用；元数据、URL、短摘录 |
| LangGraph GitHub Releases Atom | free | HTTP 200，Atom Schema 合格 | VERIFIED/启用；登记仓库 Release 元数据/URL/短摘录 |
| Hacker News API | free | HTTP 200，JSON Schema 合格 | VERIFIED/启用；发现元数据/URL/短摘录，不把热度当事实证据 |
| arXiv API | free | 本轮未探测 | UNVERIFIED/禁用；PDF/源码仍需逐篇许可 |
| GDELT DOC API | free | 本轮未探测 | UNVERIFIED/禁用；发现 URL 不等于第三方正文授权 |

三项实际探测均经 `SafeHttpTransport`、固定解析 IP、原 Host TLS SNI/证书验证、禁环境代理、响应体/重定向限制和来源专用顶层 Schema 校验。没有调用收费未知接口，也没有因为 arXiv/GDELT 未准入而扩大权限。

## 限流与历史边界

- Google RSS 没有官方稳定历史/限流承诺，按最新 Feed 与保守单并发读取，不承诺补齐任意历史窗口。
- GitHub 公共资源遵守匿名 REST/平台限流与次级限流；本轮使用公开 Atom Feed，固定到登记仓库。
- HN 官方 API 当前声明无速率限制，但本项目仍按单并发、有限 item 数执行。
- 三项都只作为免费公开信息入口；具体第三方文章正文仍受原站条款约束，不长期保存整页正文。

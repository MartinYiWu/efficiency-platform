# I05 规格与质量审查

## 审查范围

审查覆盖 I05 计划、任务简报、语义目录、参数 Schema、Binder、DecisionPolicy、测试与报告。项目规范禁止 Git，因此以当前文件、反例和新鲜测试输出进行文件级审查；未调用真实模型、网络、研究工具或数据库。

## 审查过程

审查采用四轮反例驱动：

1. 目录来源轮：核对 11 个能力与真实枚举、CapabilitySpec、AgentSpec 一一对应，版本/权限/输出/依赖可追溯且目录版本确定。
2. 绑定安全轮：验证未知候选不回退、未授权不执行、参数注入/字符串冒充整数/bool 冒充整数均拒绝，任一失败不留下部分计划。
3. 决策优先级轮：验证技术错误优先于歧义、UNSUPPORTED 优先于澄清、每轮只有一个最高优先字段、无完整计划不能 READY。
4. 架构守卫轮：全量测试发现语义目录读取场景测试期望字段，改为只投影生产清单交付要求和输出契约；同时新增未知澄清字段失败关闭，避免可信身份字段进入用户澄清。

以上问题均在 I05 内修复并增加回归。

# R06 规格与质量审查

## 审查过程

1. 桶边界轮：验证同实体/显式版本/邻近时间进入有界桶，61 条输入被拆成不超过 30 条的调用，模型不能跨桶引用。
2. 成员身份轮：覆盖未知 ID、跨桶 ID、同一文档重复分配和重复输入，全部失败关闭。
3. 事件语义轮：覆盖同发布转载、发布与事故、v1/v2、跨语言同事件；类型/版本冲突不会为凑数量硬合并。
4. 陈旧输出轮：Brief digest 或 Prompt 版本不匹配的提案被拒，成员降为 singleton uncertain，不能沿用旧模型结论。
5. 守恒与稳定轮：确认每个文档恰好进入一个最终事件，成员和代表合法，输入反序不改变 stable event_id。
6. 来源家族轮：覆盖同文通稿、同 ownership group、不同域名和独立 primary；不同域名或 unknown 不自动成为独立佐证。
7. importance 轮：确认只用显式等级、用户维度解释码、新近性和 stable event_id，不从文档数量猜重要性。
8. heat 轮：发现跨采集时刻横向归一化风险，新增 snapshot_id、同快照时间一致性和最新可比快照选择；rank 指标反向归一化。
9. 趋势声明轮：确认缺失热度为 unknown，当前快照不输出涨幅或“全网热度”，原始平台指标不直接求和。
10. 评估轮：新增人工全集上的 pairwise precision/recall 和误合并/漏合并对，避免只报告压缩率。
11. 边界轮：确认没有 Claim/Evidence 接受、质量完成、真实模型调用或网络访问，真实来源仍关闭。
12. 回归轮：执行 R06 定向、全仓 Ruff、全 src mypy 和全量 pytest，未发现新增回归。

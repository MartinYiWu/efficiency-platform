## 全局边界

- 只实施 S1 的框架中立离线底座，不接入 Harness、LangGraph、真实 Provider、数据库或业务 Specialist。
- 新增注释和 Docstring 必须使用中文；不得写入任何账号、密钥、连接串或真实业务数据。
- 每项实现必须保留 RED/GREEN 测试证据；每项完成后须经独立任务审查通过。
- 未经计划明确授权，不新增第三方依赖、动态导入、目录扫描、注册副作用或 Git 相关流程。
- 用户明确确认的独立配置治理：本机 `.env` 只校验结构和中文注释，不校验真实可调用值；模板和路由仍严格校验。该维护不属于 Agent 功能，不得作为 Agent 或 Provider 可用性证据。
- 本轮交付治理授权只覆盖计划、账本、两份权威规范和阶段报告；不读取、不记录、不写入 `.env` 值、Key、令牌、密码、连接串或其他 Secret。

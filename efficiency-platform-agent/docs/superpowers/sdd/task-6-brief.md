# Task 6 实施简报：工程文档模板

## 1. 目标

根据 `docs/standards/09-文档命名与变更治理规范.md` 建立可直接复制使用、不会诱导虚构内容的五类工程文档模板，并使文档治理契约全部通过。

## 2. 唯一允许变更的文件

- 创建 `docs/templates/架构设计文档模板.md`
- 创建 `docs/templates/ADR决策记录模板.md`
- 创建 `docs/templates/技术组件选型模板.md`
- 创建 `docs/templates/实施计划模板.md`
- 修改 `docs/templates/SQL变更说明模板.md`
- 创建 `docs/superpowers/sdd/task-6-report.md`

不得修改其他项目文件。

## 3. 通用模板约束

- 模板自身状态为 `草案`；模板复制生成的新文档默认状态也必须是 `草案`。
- 五份模板使用一致的文档头结构，与 `09` 规范一致：标题、状态、作者/负责人、创建日期、最后更新日期、评审人/批准人、关联 ADR/设计/计划、替代关系、适用范围。
- 待填写内容必须使用含义明确的 HTML 注释，例如 `<!-- 填写负责人姓名或团队 -->`；不得使用省略号、占位缩写、虚构人名、虚构批准、虚构测试或虚构生产数据。
- 填写说明必须区分“计划”“已执行”“已验证”；没有证据时不得把计划写成完成。
- 保持纯 Agent 侧边界，不加入 Java 端或部署架构设计，不创建具体业务方案。
- 模板中的规则词仅在表达强制规则时使用 `MUST`、`MUST NOT`、`SHOULD`、`MAY`。
- 内部链接必须采用可解析的相对路径。

## 4. 架构设计文档模板

章节按以下顺序完整提供：

1. 元数据
2. 背景
3. 目标
4. 非目标
5. 现状
6. 约束
7. 候选方案
8. 架构图
9. 组件职责
10. 执行流与数据流
11. 状态模型
12. 错误模型
13. 安全设计
14. 可观测性
15. 测试与验证
16. 迁移与兼容
17. 风险与缓解
18. 待决策项
19. 验收标准

必须提示架构图使用 Mermaid 或纯文本并说明边界；组件职责要含所有者、输入、输出、依赖、禁止依赖；验证项需要命令、预期、实际证据三个字段。

## 5. ADR 决策记录模板

章节按以下顺序完整提供：

- 状态
- 日期
- 决策者
- 关联设计
- 背景
- 驱动因素
- 候选方案
- 最终裁决
- 正面后果
- 负面后果
- 风险与缓解
- 替代/废弃关系
- 复审条件

状态仅允许草案、评审中、已批准、已废弃；不得在模板中预选“已批准”。候选方案要求同一评价维度；最终裁决必须记录证据和未选择原因。

## 6. 技术组件选型模板

章节按以下顺序完整提供：

- 能力需求
- 硬约束
- 候选组件
- 功能矩阵
- 成熟度
- 许可证
- 费用
- 自建成本
- 安全
- 可观测
- 生态
- 兼容性 PoC
- 最终选型
- 接入边界
- 退出策略

必须区分免费额度、按量付费、固定订阅、自建资源成本和迁移/退出成本；许可证需记录名称、版本、使用边界和法律复核状态；PoC 需记录环境、数据、指标、命令、预期、实际、证据路径，未执行时如实标注未执行。

## 7. 实施计划模板

章节按以下顺序完整提供：

- 目标
- 范围
- 非目标
- 前置条件
- 文件清单
- 分阶段任务
- 每步验证
- 数据库影响
- 配置影响
- 安全
- 回滚
- 风险
- 完成定义
- 交付证据

任务必须细化到可验证步骤；数据库部分必须显式写“无”或关联 SQL 变更包，不得隐式执行；配置需要列出键、来源、敏感性和默认值；完成定义不得用“代码已写”替代验证。

## 8. SQL 变更说明模板对齐

保留 Task 4 已建立的授权、bootstrap、原子执行权、预检、执行、验证和回滚内容，不得放宽。

补齐或对齐以下元数据：

- 状态默认草案
- 关联 ADR
- 关联架构设计
- 关联实施计划
- 评审人/批准人
- 执行审批人（与设计批准人区分）
- 替代关系和适用范围

不得把模板填写提示写成已经获得授权或已经执行。

## 9. 验证

至少执行：

```powershell
python --version
python -m unittest tests.governance.test_documentation_contract -v
python -m unittest discover -s tests -v
```

预期：文档治理契约 5/5 PASS；全量测试 15/15 PASS，0 failures，0 errors，0 skipped。

另外执行模板占位扫描，确认没有含义不明的省略号或常见未完成标记；报告中写出实际扫描表达式和结果。

## 2. 已确认根因

1. 当前 `LocalExecutionLogger` 只观察 Run 生命周期和公开终态视图，无法恢复 Provider 边界已经丢失的诊断事实；
2. `DeepSeekWebSearchProvider` 把客户端能力缺失和所有调用异常统一映射为 `RESEARCH_UNAVAILABLE`；
3. GraphRuntime 与 Harness 在吞掉未处理异常并失败关闭时没有记录安全异常类型与位置；
4. 身份和能力快答 Token 为 0 是本地确定性回答的正确事实，不属于日志错误。

## 3. TDD 与复核结论

1. 两轮独立审查发现并关闭了六项重要缺口：流式普通异常未归一化、恢复链缺少 Run 上下文、后台异常阶段与错误码不准确、OpenAI SDK 隐式重试、`APITimeoutError` 超时误分类、Graph 恢复异常被错误标记为首次执行失败；
2. 诊断数值字段拒绝浮点数、非有限数和布尔值，ContextVar 已覆盖嵌套与并发隔离；
3. `complete()` 与 `stream_complete()` 均记录模型开始、成功、失败和降级，Provider 解析失败也形成完整诊断；
4. DeepSeek 每次实际 HTTP 请求使用独立本地调用 ID，显式重试不会与下一次网络尝试混为一条；
5. 研究成功、无来源和非法来源只记录有效/拒绝数量，不记录 URL、标题、发布者或响应正文。

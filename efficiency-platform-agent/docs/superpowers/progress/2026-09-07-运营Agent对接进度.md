# 运营 Agent 对接实施进度

## 总体状态

- A～F：已完成实现、定向验证和独立复核。
- G：已完成离线协议验收、确定性浏览器场景矩阵、真实 HTTP Fake Agent E2E、真实 DeepSeek 小规模验收和页面联调；真实联网检索因门禁默认关闭而未执行。
- 当前结论：达到开发环境前后端联调体验标准；尚不等于生产就绪。

## Task A：版本化契约

- 已冻结会话消息、提交响应、结构化意图、Run 展示状态、SSE 事件、引用、单平台交付物和交付物集合契约。
- 请求、事件和交付物均拒绝未知字段；附件字段首版只允许空集合。
- `request_id`、`run_id`、事件序号和契约版本均有稳定校验。

## Task B：异步 Run 与 SSE

- 已实现 queued 立即响应、后台执行、事件历史回放、实时订阅、`Last-Event-ID` 去重、keep-alive、终态补偿和协作式取消。
- 取消受理与图终态提交使用同一状态锁线性化；已受理取消不会被晚到的成功或等待输入结果覆盖。
- Run 核心终态与前端展示态分离，允许 `degraded_succeeded` 展示。

## Task C：DeepSeek 与模型池接口

- 默认本地组合根使用真实 DeepSeek；Fake 只允许显式测试模式。
- 已实现 OpenAI-compatible Chat 完整响应和流式响应适配、错误归一化、有限重试、候选模型降级、绝对截止时间及响应释放。
- 已保留逻辑模型池和能力分级接口；当前真实环境仍只有用户配置的 DeepSeek 候选，尚未形成跨供应商冗余池。

## Task D：意图、澄清和场景解析

- 已实现八类运营场景的结构化意图解析、JSON Schema 修复、受控场景解析和需求缺口判断。
- 会话上下文有轮数和字符上限，不传递隐藏思维过程。
- 澄清轮保存 Resolver 推导的实际缺失字段，只补齐缺失项，不覆盖已确认的渠道和平台范围。
- 当前平台白名单为小红书、微信公众号、今日头条，支持中英文别名；未知或混合未知平台稳定拒绝，禁止扩大为全部平台。

## Task E：多 Agent 运营主链

- 已接通 `GraphRuntime → OperationAgent → ScenarioPackService → Supervisor → Specialist → QualityGate → DeliverableSet`。
- 已覆盖行业动态、多平台内容、品牌运营、IP 运营、活动策划、内容日历、增长实验和运营复盘。
- 多平台请求按平台独立生成；单平台请求只编译对应步骤；部分 Specialist 失败时保留已完成成品并披露缺口。
- 研究 Specialist 已接入受控 `ResearchProvider → EvidenceGate → Citation` 链路；公开检索门禁默认关闭。

## Task F：运营助手前端

- 页面已接入 FastAPI 会话接口和 SSE，不再使用本地固定回复。
- 已实现提交、流式消息、澄清、停止生成、失败态、独立平台交付物、引用、格式说明和降级提示。
- 使用 `requestId + runId + generation` 隔离陈旧事件；支持 SSE 重连、游标续传、去重和组件卸载取消。
- Hook 已通过 `AbortController` 将卸载信号传递到会话 POST 和 SSE，避免离开页面后继续读取或重连。
- 前端没有 DeepSeek Key，也没有直连模型供应商。

### 真实联调证据

- 三平台请求由后端集成测试和确定性浏览器矩阵验证返回 3 份独立交付物；真实 DeepSeek 仅执行单平台代表性样本。
- 最终脱敏 CLI 复验再次成功：`degraded_succeeded`、8 个 SSE 事件、1 个交付物、输入 1063 Token、输出 3520 Token。
- 信息不足请求进入 `waiting_input` 并展示澄清问题；补充信息后创建第二个 Run 并生成成品。
- 取消请求真实进入 `cancelled` 并返回 `stream_done`。
- 浏览器页面真实完成 `POST /v1/conversations/**/messages`、`GET /v1/runs/**/events` 和交付物渲染；浏览器控制台无错误或警告。
- 已补充本地开发 API 地址配置，避免 Vite 将 `/v1/**` 错误回退到 SPA 页面；配置不含任何密钥。
- 确定性浏览器矩阵覆盖普通内容、三平台、活动策划、行业热点引用、澄清、Specialist 部分失败、取消和 `Last-Event-ID` 重连。
- 独立 Playwright 配置同时启动真实 FastAPI Fake Agent 与前端，不使用 `page.route`，网络白名单、敏感请求头和控制台断言均通过。
- 真实模型存在偶发意图超时和结构化输出无效；页面能安全显示失败，但在第二模型候选接入前不判定为生产稳定。

### 流式语义边界

- DeepSeek Provider 的真实流式接口和 ModelRuntime 降级协议已有专项测试。
- 运营多 Agent 主链先完成结构治理和质量门，再把安全正文分块为 `assistant_delta` 通过 SSE 输出；当前不把未经质量门的模型原始 Token 直接推给前端。
- 因此当前结论是“真实 SSE 增量呈现”，不是“所有 Specialist 的原始 Token 实时透传”。

# AI行政助手UI设计规范
**A 段全局前缀每次调用都粘在最前面，B 段选对应页面，C 段负面约束粘在最后**，三段拼成一次完整请求。

先说三条使用前提，避免生成偏：

1. 全部页面都在 `AI 助手 → AI 行政助手` 之下，不是一级菜单
2. **P10–P13 是行政管理员专属**，生成时左侧菜单要出现「制度管理」；P1–P9 生成时该菜单项不出现
3. 全程不含行政台账、资产、费用、工单流转，也不含红头文件排版和录音转写

# A 段 · 全局设计系统前缀（每次调用必带）

```
你是一名资深企业级 SaaS 前端 UI 设计师，精通 shadcn/ui 与 Tailwind 企业后台
设计规范，擅长信息密度中等偏高的内部工具界面。

【产品背景】
产品：企业内部 WEB 端 AI 效能平台
模块：AI 助手 → AI 行政助手
用户：企业内部行政专员、行政管理员、普通员工
定位：AI 只产出草稿与建议，任何对外生效动作必须人工确认后才生效

【语言】
界面全部使用简体中文。所有示例数据必须是真实感中文内容
（真实的制度名、公文标题、人名、日期），禁止出现 lorem ipsum、
placeholder、示例文本、English label 等占位符。

【页面骨架】
- 顶部导航栏高度 56px，白底，底部 1px 分割线；左侧平台名「AI 效能平台」，
  右侧依次为全局搜索图标、消息图标、用户头像+姓名
- 左侧主菜单宽 240px，白底，可折叠；菜单层级为：
  工作台 / AI 助手 / 知识中心 / 素材中心
  其中「AI 助手」展开，其下子项为「AI 人事助手」「AI 行政助手」，
  「AI 行政助手」展开并高亮，其下子项见各页面说明
- 右侧内容区底色 #F9FAFB，内边距 24px，内容最大宽度 1440px 居中
- 内容区顶部固定结构：面包屑（12px 次级文字）→ 页面标题（20px 半粗）
  → 同行右侧放主操作按钮

【视觉令牌 · 严格使用以下色值】
主色 #2563EB      主色深(hover) #1D4ED8    主色浅底 #EFF6FF
成功 #16A34A      警示 #F59E0B             危险 #DC2626
一级文字 #1F2937  次级文字 #6B7280         禁用文字 #9CA3AF
分割线 #E5E7EB    页面底色 #F9FAFB         卡片白 #FFFFFF

【排版】
字体族 Inter, "PingFang SC", "Microsoft YaHei", sans-serif
页面标题 20px/600｜区块标题 16px/600｜正文 14px/400｜辅助文字 12px/400
行高统一 1.5，禁止使用小于 12px 的字号

【间距与圆角】
全局遵循 4px 原子网格：4 / 8 / 12 / 16 / 24 / 32px
卡片内边距 24px，区块垂直间距 24px，表单项垂直间距 16px
卡片圆角 8px，按钮圆角 6px，输入框圆角 6px，标签圆角 4px
卡片阴影极轻：0 1px 2px rgba(0,0,0,0.04)，禁止厚重多层阴影

【状态标签配色规范】
生效 / 已完成 → 底 #DCFCE7 文字 #15803D
待生效 / 进行中 → 底 #DBEAFE 文字 #1D4ED8
未开始 / 草稿   → 底 #F3F4F6 文字 #4B5563
逾期 / 已废止   → 底 #FEE2E2 文字 #B91C1C
AI 生成角标     → 底 #EFF6FF 文字 #2563EB，12px，右上角，圆角 4px

【全局必须遵守的六条规则】
1. 所有 AI 生成的内容区块，右上角必须带「AI 生成」浅色角标
2. 任何对外生效的动作（发布、下发、废止、提交），主按钮点击后必须
   经过二次确认层，不做一键直发
3. 每个列表页都必须同时画出「有数据」与「空状态」两种版本；
   空状态 = 极简线性插画占位 + 一句中文引导文案 + 一个主操作按钮
4. 表格与列表必须画出加载态：骨架屏，灰条脉冲，不使用旋转 loading 遮罩
5. 交互反馈克制：卡片 hover 阴影加深不位移，按钮 hover 背景加深 10%，
   过渡统一 150ms ease-out，禁止缩放、弹跳、闪烁
6. 响应式：≥1280px 完整布局；1024–1280px 侧栏折叠为 64px 图标栏；
   <1024px 双栏改单栏纵向堆叠，表格横向滚动
```

## 使用顺序

1. 阅读对应模块的功能规格，确认业务边界、角色、数据与明确不做项。
2. 阅读交互与 UI 规格及设计稿说明，定位页面、状态和视觉验收依据。
3. 查阅需求页面追踪矩阵，确认需求、页面、设计稿与工程实现归属。
4. 技术实现只在各开发工程内按其自身规则编写；本目录不承载代码、接口实现或部署资料。

文档命名、状态、归档和链接规则见 [产品文档治理规范](00-治理/产品文档治理规范.md)。

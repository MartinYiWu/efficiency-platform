## 功能规格必备章节

1. 模块定位与用户角色。
2. 全局业务规则、数据边界、权限边界和明确不做项。
3. 按功能域编排的可验收能力；每项使用稳定需求编号。
4. 与 UI 页面、后端领域、前端路由、Agent 能力的追踪关系。

## 交互与 UI 规格必备章节

1. 页面地图、页面编号、角色可见性与主操作。
2. 页面状态：有数据、空状态、加载、错误、成功或确认状态。
3. 视觉令牌、布局规则、可访问性与响应式约束。
4. 明确不做项，以及与功能规格冲突时的处理规则。

当前已存在 27 张页面设计稿和 1 张组件与状态规范稿，但尚无独立的页面地图、角色可见性、状态定义、响应式规则和页面级明确不做项。本文件只记录缺口，不以设计稿反推或虚构业务规则。

补齐 UI 规格时必须先形成页面编号与功能规格第 1–55 项的映射，再确认以下内容：

1. 每张页面的角色、入口、主操作、空状态、加载态、错误态和成功/确认态。
2. 内容发布、周报归档、数据导入、活动模板和配置变更的人工确认边界。
3. 导入数据、外部信息源、品牌规范、禁用词和生成内容的权限与审计边界。
4. 当前设计稿与前端既有组件库、响应式规则之间的实现映射。

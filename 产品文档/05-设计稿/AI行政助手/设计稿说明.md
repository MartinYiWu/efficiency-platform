# AI 行政助手设计稿说明

本目录保存[AI 行政助手 UI 设计规范](../../03-交互与UI规格/AI行政助手/2026-09-02-AI行政助手-UI设计规范.md)定义的高保真桌面端设计稿。全部设计稿以 P1「行政问答主页」作为视觉母版，画布统一为 1440×900。

## 目录结构

- `01-行政问答/`：P1 行政问答主页，以及首次进入、检索中、未找到依据、反馈已提交四个关键状态。
- `02-文书助手/`：P2 至 P5，文书工作台、文书生成、文书编辑、发布前确认。
- `03-会议纪要/`：P6 至 P9，纪要列表、新建纪要、纪要详情、待办看板。
- `04-制度管理/`：P10 至 P13，制度管理列表、制度上架/改版、制度详情、确认变化点；仅行政管理员视角展示制度管理菜单。

## 共用视觉与产品边界

- 固定 240px 左侧菜单与 56px 顶栏，内容区采用 #F9FAFB 底色、白色 8px 圆角信息面板、轻量边框与阴影。
- 主色为 #2563EB；成功、警示、危险状态分别使用绿色、橙色、红色，AI 输出区域统一带「AI 生成」角标。
- 所有 AI 内容仅作草稿或建议；发布、上架、废止、提交等对外生效动作必须通过人工二次确认。
- 不呈现资产台账、费用汇总、工单、审批流、红头文件、录音或实时转写等受限能力；顶栏不使用消息红点。

后续页面实现时，以同一菜单目录的设计稿为验收目标，业务字段与交互边界以[AI 行政助手 UI 设计规范](../../03-交互与UI规格/AI行政助手/2026-09-02-AI行政助手-UI设计规范.md)和[功能规格](../../02-需求规格/AI行政助手/2026-09-02-AI行政助手-功能规格.md)为准。
